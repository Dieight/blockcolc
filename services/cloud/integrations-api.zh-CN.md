# 第三方接入 API

## 配置

在方块钟设置的「账户与云同步 → 第三方接入」生成每个软件自己的令牌。可以分别授权上报专注、读取好友，按需设置有效期。对接软件保存令牌，所有请求使用 HTTPS 和 `Authorization: Bearer <令牌>`。服务端从令牌识别账号。令牌只在创建时交付一次，可在原入口撤销。

通过 `https://blockcolc.arcol.site` 调用下面两条公开接口。公报页自身使用的登录 Cookie 与此令牌独立。接口错误响应中有 `error`，未授权为 401，权限不足为 403，另有专注正在进行为 409。开始使用前请把参与云同步的方块钟客户端升级到 v3.1.0 Beta 5 或更新版本，以便读取外部专注记录。

## 上报实时专注

`PUT /v1/integrations/focus`，JSON 请求正文。

```json
{
  "state": "focus",
  "sessionId": "morning-reading-1",
  "sequence": 1,
  "taskName": "读书",
  "estimatedEndsAt": "2026-11-25T02:25:00Z"
}
```

- 一个 `sessionId` 对应一个任务的一场专注。更换任务时结束原会话并用新 ID。每次状态变化或续报递增 `sequence`，网络重试重新提交同一个编号和内容。任务名与预计结束时间可省略。
- 开始及续报使用 `focus`，休息使用 `rest`，结束使用 `idle`。休息期间也需要续报以保留本场的执行权。建议每 15–30 秒上报一次，仅在进入下一状态或续报时更新编号。
- 实时开始及续报返回 `accepted` 和 `expiresAt`。服务器按收到的时间计算已确认的专注区间。90 秒未续报会释放执行权，结算截至最后一次确认的专注片段。
- 结算返回 `settled`、`focusMs`、`rounds` 和 `projectId`。相同会话的重试返回原结算结果。收到 `NATIVE_FOCUS_IN_PROGRESS` 或 `EXTERNAL_FOCUS_IN_PROGRESS` 时，用对应提示告诉用户已有一端在专注。
- 兼容软件可以在结束后补传一段离线记录。使用 `state: "recorded"`、全新的 `sessionId` 和 `sequence: 1`，带上 ISO 8601 的 `startedAt`、`endedAt`。支持最近 30 天内、最长 24 小时的实际专注区间。休息应拆成不计入的空档。已经同步的时间优先，只计入未重叠的部分。

## 读取好友

`GET /v1/integrations/friends` 返回 `account`（ID 和显示名）及 `friends`。仅包含已确认、且允许第三方查看其分享的好友。实时状态、任务名、时间和每日记录分别按好友的分享权限返回。字段缺失表示该字段未获准显示，或当前没有可用记录。

## 统计和建造

结算后的实际专注片段与方块钟记录共用历史。只把完整轮次推进到习惯建筑。同名且唯一的现有习惯优先，其余汇入「外部专注」。默认习惯的蓝图来自普通内置蓝图。已匹配习惯落成后沿用上一座的蓝图，多余轮次进入下一座。开始新一座时采用账号当前的目标轮数。零碎时长按习惯和当时的轮长留存。
