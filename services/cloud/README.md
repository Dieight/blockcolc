# blockcolc 账户服务

Node 24 LTS，使用内置 HTTPS、密码派生和 SQLite。领域验证直接构建自本仓库的 TS 领域模块。Android 的同步适配器位于 `apps/native-android/platform-cloud`；页面与计时业务仍通过现有原生写入队列保存。

## 本地验证

在本目录执行 `npm test`。测试使用临时目录、合成账号和模拟公开来源，退出后清理。HTTP 工厂仅供回环测试；生产入口要求明确的数据目录、TLS 证书和密钥。

`node tools/build.mjs` 生成可重建的 `build/domain.mjs`。`python tools/deploy.py --reuse-tls` 更新现有独立 systemd 服务，沿用带 IP SAN 的 HTTPS 证书。续签服务端证书时需要原账户服务 CA 与私钥。Android 使用仓库中的公开 CA 证书 `blockcolc-cloud-ca.pem`，出包时核对其已正确封装。私钥和部署包保存在忽略目录中。

当前部署使用 8443。服务器安全组还需允许该端口；服务内部 HTTPS 成功不能代替公网可达性。`tools/test-proxy.py` 是只监听电脑回环地址的实验桥，需要独立 SSH 转发；不随 App 打包，也不跳过 TLS 校验。

## 数据与恢复

- `/var/lib/blockcolc-cloud`：按账号隔离的 SQLite 与蓝图内容块。服务身份独占写入；登录令牌只存哈希。
- 建筑包和专注包各自有版本及 SHA-256。前台客户端每 10 秒读取 `GET /v1/sync/head`，包头变化时按版本拉增量。索引保留 512 个包版本的变更，过旧的客户端拉取对应包的快照。
- 专注状态、历史、日累计和相关奖励在同一事务提交。空闲时先提交成功的设备取得执行权，并发冲突自动采用已提交的状态。审核和恢复用的本机回滚点保留落败端的修改。
- 服务端持久保存专注状态，已过时间由客户端按服务端时间锚推算。开始、续轮、休息和结束改变事实时立即提交。第三方报告仍按其公开接口的时限结算。
- 每日根和实时工作区分开。每日根先校验再事务换入，内容块去重，稳定时只留一份；主动恢复更换工作区代次，不恢复本机提醒或自动继续许可。
- 导入蓝图可同步；材质包和音频原件、登录凭据、天气配置、位置及派生缓存不上传。缺失素材的本机回退不改变共享选择。
- 好友需邀请确认。状态、任务名、起止时间及每日时长分别授权，服务端只返回获准投影。

Android 的上传队列与本地保存分开。包头读取有 8 秒期限，失败保留本地内容，并于前台每 10 秒重试。连续三次失败时，主页红色同步横幅覆盖导航区，重新同步操作显示下次自动重试的秒数。同步成功或选择忽略后恢复导航。

升级时先制作独立 SQLite 备份。新服务首次启动在事务内把旧 `entries` 导入 `sync_entries`，并校验同步包及好友投影可以重建。旧客户端的同步请求返回 `CLIENT_UPDATE_REQUIRED`。Android 首次同步读取原有的基线和记录，补发本地变化。切换后如需回滚，应把数据备份和旧服务版本一同恢复。

账户服务以独立系统账号运行。数据库、WAL 和 SHM 使用 0600，并设置 `UMask=0077` 与 `LimitCORE=0`。数据库快照应由 SQLite 在线备份接口生成，校验完整性后再与按摘要核对过的蓝图内容块一起归档。数据库恢复及 CA 私钥管理是独立操作。

云服务条款与隐私说明按[简体中文](policy/zh-CN.md)和[英语](policy/en.md)维护。Android 从账户页打开，专注公报提供 `/legal` 与 `/legal/en`。同一份说明随应用和服务构建。

## 专注公报

专注公报直接从自有服务器上指定账号读取实时状态与每日时长。公报会话走域名的 HTTPS 入口，App 继续使用 8443。朋友需要服务端读取时，按[公报 API 接入说明](focus-viewer-api.zh-CN.md)使用自己的账号登录。

## 第三方双向接入

账户页签发独立令牌。具备相应权限的软件可上报和结算本人的专注，也可读取好友授权披露的数据。公开域名仅转发这两条集成接口。详见[第三方接入 API](integrations-api.zh-CN.md)。

## Mutsumi Focus 只读来源

`external-focus.mjs` 只访问 `https://platform.arcol.site` 的访客入口和公开看板。使用独立、仅在内存保留的 Cookie；不需要上报 key，不调用专注、打卡或计划的写接口。配置里的 `username` 可指定要读取的账户，首次接入时应固定该值，避免以后站点所有者变化时读错人。相同来源 ID 不允许改绑另一外部账户。

服务每 30 秒读取一次，失败后等待 60 秒；实时投影最长保留 90 秒有效期。失败立即停止展示旧数据，保留最后一次成功回执供诊断。只保存当前专注、暂停状态、事项名称、真实开始时间和最多 366 天的日时长；对方没有提供确定结束时刻时留空。不保存整个看板，不把成绩、打卡、私有计划或外部会话写入本项目的任务和专注历史。

每个来源分配一个不能登录的只读账号，账号和好友码持久化。用户启用好友后主动添加其好友码即可查看，不需要模拟对方确认，也不会向对方披露本机内容。普通用户之间仍需邀请确认及独立的分享授权。移除来源配置后停止展示，保留已有好友关系；不自动给所有用户添加这个好友。

用 `node tools/probe-external.mjs <配置文件>` 在隔离数据库中核对真实接口，只输出状态和数量。配置格式见 `external-focus.example.json`。通过后执行 `python tools/configure-external.py --configuration <私有配置路径> --apply`：先校验，备份数据库和旧配置，再更新独立配置并重启本服务。生产服务从 `/etc/blockcolc-cloud/external-focus.json` 读取，访客 Cookie 不写入配置或日志。
