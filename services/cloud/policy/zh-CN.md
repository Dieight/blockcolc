# 方块钟云服务条款与隐私说明

更新日期：2026-11-20

## 使用云服务

方块钟可离线使用。注册或登录后，你可以在自己的设备间同步记录、保存一份每日合并备份，并选择是否加入好友功能。

请使用自己的账户，妥善保管密码，只上传你有权使用和分享的蓝图及其他内容。请勿尝试访问他人记录、干扰服务或滥用好友邀请。

同一计划由一台设备执行，你可以在其他设备上接管。网络断开时先保留本机记录。发生同步冲突时，请确认要合并或替换哪一份数据。替换云端和恢复备份会改变共享工作区。重要记录可以另行导出到本机。

## 处理的数据与用途

账户服务保存用户名、显示名称、时区、密码的加盐校验值和登录会话的哈希。设备标识、设备名称及最近访问时间用于管理登录和专注接管。连接来源地址用于请求限速。

工作区同步任务、专注记录、便签、建筑及奖励记录、导入的蓝图和部分偏好。云服务保留当前工作区与一份合并恢复快照。材质包、音频原件、位置和日期倒计时留在本机。

应用开启现实天气后，会将位置发送给和风天气来获取天气及天文数据。关闭后使用本地天气。检查应用更新会向 GitHub 请求发布信息，不附带方块钟账号或专注记录。

## 好友及专注公报

好友功能默认关闭。开启后可选择分享专注状态、事项名称、起止时间和每日专注时长。普通好友需接受邀请。你可在账户或好友详情里调整共享范围。

登录专注公报可以查看站点所有者提供的专注数据。当天到访的用户名与时间、按账号累计的访问次数仅站点所有者可查看。浏览器保存登录所需的会话 Cookie。

## 保存与安全

账户服务通过 HTTPS 传输。密码使用带随机盐的 scrypt 校验，登录令牌仅保存哈希。云端存储可由服务器维护者访问以维护和恢复服务，云同步不提供端到端加密。

登出或移除设备会停止该设备的登录。同步工作区和恢复快照保留到替换或按请求删除。访客详细时间在隔日清理，访问次数继续累计。受限的运维恢复副本可在轮换期间保留历史数据。

## 管理你的数据

你可在设置导出本机 JSON、修改密码、退出登录、撤销设备或关闭好友共享。登出会保留本机记录和已经同步的云端记录。账号注销、数据副本、更正、删除等请求可联系方块钟项目维护者。可先通过项目仓库发起联系，公开内容请勿附带账号凭据、备份或专注明细。
