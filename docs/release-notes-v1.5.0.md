# Blockcolc v1.5.0 发布说明

## 活着的世界

- 云会缓慢漂移、树木绕根部轻轻摇曳——世界在前台时始终在呼吸，切走或锁屏立即静止；系统开启「移除动画」或选择「流畅」光影档时自动停用。
- 完成一轮专注后，建筑不再瞬间出现：新方块按蓝图顺序自下而上逐块落位，每块带轻微回弹，约 3.5 秒建完；减少动态设置下保持瞬间完成。
- 环境动画帧与交互帧共用渲染通道，并按实际帧耗时自适应节流，不会拖慢操作或空耗电量。

## 手感打磨

- 计时数字在跳动时轻滑入位；主按钮按压有下沉回弹；底部导航激活图标轻微弹起。
- 条件出现的控件（沉浸结束按钮、进度报告、弹窗、计划面板、有效离开计数）统一轻淡入，关闭时对称下移淡出。
- 修复了切光影档或负载降档时河流瞬间描白边的闪烁——降档现在静默进行，只调整分辨率与后处理。
- 当前小任务卡片的绿色竖条改为真正的垂直条。

## 数据与兼容

- 本版本不改变存档结构、备份格式或资源包清单；老世界直接受益，无需迁移。
- 验证：全量单测与 web E2E 全绿；候选 APK 在授权设备上安装并核对 SHA-256；云速、树摆、逐方块建造与各弹入弹出动画均经真机验收。
