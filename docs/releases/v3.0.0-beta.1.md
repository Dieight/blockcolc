# blockcolc v3.0.0-beta.1

这是 v3.0.0 原生 Android 版的第一期公开 Beta。使用正式包名及签名，支持在旧版上覆盖安装。更新前可在「设置 → 高级与备份 → 本地备份」导出一份 JSON 留存。

## 本版变化

- 安卓界面、计时、存储和世界渲染迁移至原生实现。启动时先准备计时界面，世界随后呈现。
- 世界新增室内视角和适合低性能设备的纸雕画质。
- 可选开启账户、好友和云端备份。好友共享范围可在账户里调整。
- 设置中的备份、音频导入、账户同步等常用操作放在对应行右侧。
- 可在设置中切换 Beta 更新通道，正式版仍可从原 Release 入口下载。

## 验证与下载

Android 包名 `com.blockcolc.app`，版本 `3.0.0-beta.1 (108)`。[GitHub 预发布](https://github.com/Dieight/blockcolc/releases/tag/v3.0.0-beta.1)提供签名 APK。

精致档的世界旋转性能仍在优化。Beta 覆盖安装后，恢复旧版需要后续提供的同签名、高版本码回退包。建议保留导出的备份供恢复使用。
