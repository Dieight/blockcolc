# blockcolc v3.1.0 Beta 12

- 单体建筑与大世界视角过渡：在单体建筑展台/天光模式下切换任务（建筑）加入画廊柔幕交叠与展台入场滑移过渡动画；在大世界聚落模式下切换大任务，镜头自动平滑飞跃至对应建筑。
- 结束时间与极简磁吸精修：按结束时间专注初始直接显示当前时间，向上滑动平滑起滑无跳变；极简模式与按结束时间模式滑到轮次倍数的磁吸刻度时，大号时钟同步高亮为松绿色并触发轻弹反馈；同时补齐「按结束时间专注（含大型任务与习惯任务）结束后/提前完成后统一汇报」的结算逻辑与多组合自动验证。
- 蓝图预览升级为单体建筑展台：新建任务选图页、习惯下一栋建筑选图页与设置中的蓝图库预览统一升级为阶梯式单体建筑展台与柔和展馆布光，与深浅画布自然融合。
- 单体建筑天气与画面调试修复：修复海岛等聚落下单体建筑展台/天光背景缺失真实天气、本地天气、调试天气（含雨雪/雷暴/昼夜）的问题，以及开启/关闭画面调试后建筑腐败效果与常规环境状态无法正常复原的缺陷。
- 建房加载动画重构与细节优化：精简并重绘为单一松绿屋顶建筑展台小屋，砖瓦由地基至烟囱与真实加载进度对齐并配底部松绿细线进度条；设置页「字体」选项各自按对应字体预览（像素、系统、混合）；任务页习惯任务主进度统一改为百分比呈现；专注态「双击下方空白处唤出结束按钮」提示条改为适配浅色/深色主题的半透明纸感胶囊。
- 自动续时落块时机优化：开启「自动续专注时间」后，轮次边界不再于加时专注过程中提前触发庆祝方块落下与 3D 建造视觉刷新，改为在用户主动结束本次专注时按最终实际完成轮次统一触发呈现，确保完整看到动画。

Android 构建号为 124，可覆盖更新。
