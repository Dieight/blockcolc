# blockcolc v2.5.6

发布日期：2026-10-05。Release：[v2.5.6](https://github.com/Dieight/blockcolc/releases/tag/v2.5.6)。

## 本版变化

新增“万象海岸”：雪山、冰刺、恶地、暖海、沙滩与斑驳森林围绕建筑区域分区连接，配有杨树群、营地和连片彩色珊瑚礁。改善近景与远景地形的衔接，远处也生成云群、树、花园和村庄，数量随可用世界面积增长；已有建筑与旧地形身份保留。

日出日落加入红粉暮光与蓝调时刻，所有聚落共用繁星、银河和偶发流星，水面、玻璃与冰面响应同一片夜空；万象海岸冰雪区域另有极光。银河改用连续方向场，细化水面倒影，减少拼接痕迹。阴云、月光和天气遮挡仍生效。

补齐像素图标，收紧关于、计划与设置布局，新增像素／系统字体即时切换。玻璃与世界色彩滑杆采用像素小球，可直接滑动，也可拖动发射并预估落点；预计数值留在原位置，浅色黑字、深色白字，不加背景框。热力图分档支持高亮对应日期，最高档另标出最长专注日。

普通、马拉松和极简模式从开始专注到汇报共用沉浸流程。计划必须确认才生效，未开始的马拉松可直接取消；手动中断或提前完成后等待再次开始，不触发自动连续专注。修正最后一轮、零休息、轮次文字和汇报切换时的闪现，提交成功在按钮内显示两秒“材料已送达！”。

二十项节日提供像素挂件与简短点按介绍，节日当天和之后两天可见；三天内完成至少一轮有效专注，即可获得当年该节日的一座小建筑。奖励贴合地形，空闲时可点选查看获得日期。临时节日预览入口已移除。

建筑蓝图库容量扩大到 36 份。每日备份改为一份滚动合并档，复用未变内容、替换变化内容，最多占用 200 MiB；删除、导入和恢复前的回滚点仍单独保留，完整 JSON 导出不依赖补丁链。

整理冷启动与聚落切换的加载阶段，世界模块和天气并行准备，加载页覆盖 shader 与实际首帧成本；复用地形和渲染资源，减少提交时重复重建。备份刷新只读摘要，刷新转动自身图标，其他异步按钮使用共用像素圆等待反馈。定位按冷启动和既定间隔请求，不因返回计时页重复获取。

## 使用边界

极光是艺术化表现，不是现实极光预报；天气与天文接口没有提供日食数据，本版不推断日食。部分安卓系统仍可能回收后台，设置页提供退出记录和电源管理入口，不保证系统永不回收。已有用户设置、任务记录与建筑快照不重置。
