# Blockcolc v2.2.0

2026-10-01 已发布：[GitHub Release](https://github.com/Dieight/blockcolc/releases/tag/v2.2.0)。

本版修复建筑阴影的缓存、切档和上下文交接问题；雨雪增加像素层次，旋转世界时继续运动，极简面板积雪按降雪量非线性分为四档。极简结算采用更轻的玻璃表面，玻璃边缘从真实世界帧采样折射；数字输入、折叠滑条、施工清单编辑和现实天气归因也做了调整。

环境装饰改为稳定群系斑块、逐格树木和成簇花园，加入远村庄、营地、遗迹、码头及近岸部分露出的沉船。海岛与山谷村庄进一步推远，空岛不生成村庄；不移动旧任务、奖励或改变地形高度。常规构建使用工作区已封装蓝图，不再依赖外部素材目录。

用户接受同轮私人测试包并明确授权公开标准版发布，小问题留下一版。沿用原始已完成应用门禁，并记录构建工具限域修复与两通道构建证据，未重跑未受影响全量或重建已接受候选。发布提交快速 CI、公开下载摘要与包身份、标准包私有隔离及 Latest 审计均通过；未补造逐项手机验证或标准包 Install/Accept 流程。历史跳过、失败及中断证据保留。

边界：不同 Android GPU/WebView、系统字号、OEM 后台与真实服务组合仍需持续观察；不承诺 Minecraft 完整世界生成或逐像素等价。用户尚未提供具体的下版小问题清单。

标准 APK 不含私人好友服务器同步模块；私人 APK 仅保留在本机私有工作区。
