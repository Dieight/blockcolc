# blockcolc v2.7.0

## 本版变化

- 地形和景观可从本地缓存恢复，建筑几何复用；海岸冷启动与稳定旋转减少重复工作。
- 可选渐进启动：计时与任务操作先可用，世界随后完成准备；任务、统计和设置页在空闲时预加载。
- 增加简体中文 / English 切换、简易便签和完整蓝图库；补充及奖励蓝图也有英文标题与描述。
- 自然声音支持晨间鸟鸣、导入音频及随雨天叠加的雨声，主音轨互斥；移除湖畔录音。
- 调整海岸气候交界与连片珊瑚，改进云形、火焰转场、日历翻页和玻璃界面。
- 修复多轮计数、双向面板滑动、中文便签输入、蓝图预览关闭及语言切换等问题。
- 改进 Android 后台计时交接和系统提醒，增加 OriginOS 通知适配。

## 已知限制

ColorOS 的“智能优化后台运行”可能冻结应用，影响后台连续专注。需要稳定后台交接时，可在本应用的系统电池设置中选择“完全允许后台行为”；应用不会自行改动系统策略。OriginOS 通知适配没有对应真机完成视觉验证。
