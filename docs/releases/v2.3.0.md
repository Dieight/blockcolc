# blockcolc v2.3.0

发布日期：2026-10-02。Release：[v2.3.0](https://github.com/Dieight/blockcolc/releases/tag/v2.3.0)。

## 本版变化

世界与天气一起准备好再进入开场，减少加载结束后的光照跳变。雨雪覆盖可见地形和外围，密度随视野范围调整；非晴天的日月与水面高光收敛，多云的云群更连贯，雷雨加入可见闪电。扩大山谷细节区域并收紧最远视角，修复大海岛扩张后找不到有效岸线而缺少沉船的问题。

液态玻璃改用同帧 GPU 散射合成，调整浅深主题的通透度，撤回旋转时显得怪异的边缘扭曲。极简时钟去掉外框；数字输入在浅深主题保持一致，加载动画按实际阶段呈现。

统计页热力图回到顶部，时间分配改为点簇与准确时长、占比，轮次显示完成数与累计目标，建筑档案统一背景。普通模式开场使用真实建筑焦点收尾，之后旋转、缩放及返回地图不再跳到错误限位。

树群按区域裁剪并保留完整阴影，地形合并相邻同平面面片，降低重复绘制成本；建造动画从重建后的首个有效帧开始。新增 12 张补充蓝图：9 张普通、3 张每日奖励，共 22 张。关于页与 README 补清楚项目及第三方技术、许可来源。
