# blockcolc v3.1.0 Beta 5

- 账户设置新增「第三方接入」。为外部软件生成独立令牌，可分别授权上报专注和读取好友公开给第三方的数据。
- 外部专注时长纳入统计，完整轮次推进习惯建筑。同一账号在线时由一端执行专注。
- 本地导出、每日合并备份和回滚点包含设置偏好，例如习惯任务的每轮时长和目标轮数。旧备份可以继续恢复。

Android 构建号为 117。可在设置中检查 Beta 更新，或下载下方的 APK。

[第三方接入 API 说明](https://github.com/Dieight/blockcolc/blob/v3.1.0-beta.5/services/cloud/integrations-api.zh-CN.md)
