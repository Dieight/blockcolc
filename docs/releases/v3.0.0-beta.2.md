# blockcolc v3.0.0-beta.2

原生 Android 版的第二期公开 Beta。可从 Beta 1 或使用相同签名的旧版覆盖升级。已有存档可先在「设置 → 高级与备份 → 本地备份」导出一份 JSON。

## 本版变化

- 复用静态阴影，精简地形网格和建筑内部被遮挡的方块面。大型聚落旋转更稳，绘制所需内存减少。
- 好友可按住拖动排序。好友和统计采用一致的热力图样式，专注状态变化时立即同步。
- 汇报会把不足一轮的实际专注时间均分到已分配的轮次。加时结束后直接进入对应的汇报界面。
- 更新首次使用教程，先建立或恢复工作区，再到对应页面演示操作。调整设置行的操作位置和间距，并补齐横屏日期倒计时和屏幕缺口适配。
- 切换聚落和画质时显示准备进度，目标画面就绪后再返回世界。

Android 包名为 `com.blockcolc.app`，版本为 `3.0.0-beta.2 (110)`。
