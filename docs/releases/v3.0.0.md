# 方块钟 v3.0.0

3.0 转向原生 Android。现有用户可使用同签名 APK 覆盖升级，升级前可在「设置 → 高级与数据 → 本地备份」导出 JSON。

- 提升了聚落加载、施工更新和旋转表现。新增低负载纸雕画质，以及从书房窗户看聚落的视角。
- 专注支持计划结束后加时，任务汇报会计入不足一轮的实际投入。可使用便签、日期倒计时与两种强度的雨声音轨。
- 新增可选的账户、好友和云同步。可在多设备间同步工作区、接管正在进行的专注，并独立控制好友能看到的内容。
- 极简面板可查看今日专注、便签和好友。普通模式与极简模式切换时沿用同一世界，优化了横屏和屏幕开孔处的布局。
- 从其他页面返回计时，聚落会沿用上次画面并在切页后恢复动态绘制。书房只在准备时间较长时显示加载提示。
- 统计和好友热力图的零分钟格留白，账号、天气、画质选项的说明集中在各自的气泡中。

较旧的手机在切页和旋转聚落时仍可能偶发掉帧。

离线功能可直接使用。云端服务的范围见[云服务条款与隐私说明](https://github.com/Dieight/blockcolc/blob/v3.0.0/services/cloud/policy/zh-CN.md)。
