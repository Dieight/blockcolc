# blockcolc v3.1.0 Beta 10

- 全新画廊建筑感视觉与去卡片化排版：采用画廊暖纸（浅色）与暗房曜石（深色）画布，移除冗余卡片边框、重复入口与辅助小字，保留 0dp 锐利折角与全套原生像素图标（新增 12×12 `target` 目标图标）。
- 计时页直觉手势重构：移除“调整计划”弹窗与多余标签。在巨幅裸排时钟上上下滑动直接累加轮次总时长，达到今日剩余目标轮次时触发 250ms 磁吸阻尼、触觉反馈与松绿脉冲；左右滑动时间或轻点上方双线无缝切换固定轮次与结束时间；顶部项目标题左右滑或轻点切换大任务，底部小任务栏轻点或左右滑切换小任务；右上角仅保留纯像素工具图标（复位视角仅在移动相机后出现）。
- 新增单体建筑叙事模式与双背景：在「设置 → 世界与建筑」中可切换「大世界 / 单体」，并自由选择「展台（无接缝画廊展台）」或「天光（悬浮小岛 + 真实实时天光天气）」，支持在单体舞台上直接轻扫切换建筑与对应大任务。
- 保留纯净沉浸极简体验：极简待机保持无顶部按钮与无开始按钮的双击时间启动逻辑；专注中保留原有居中三段布局，仅在倒计时下方新增 2dp 松绿细进度条。
- 工程页、好友、统计与设置全面重塑：工程页升级为建筑专著头部 + 交互式径向点阵雕塑 + 唯一今日目标入口；统计页重做去卡片热力图、L14 黄金角星座以及独立的「成就与书房陈设」「纪念建筑」展板与底栏；设置页采用裸排搜索栏与精炼六大分组，并同步更新新手教程。

Android 构建号为 122，可覆盖更新。
