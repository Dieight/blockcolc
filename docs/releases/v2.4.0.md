# blockcolc v2.4.0

版本日期：2026-10-03。Release：[v2.4.0](https://github.com/Dieight/blockcolc/releases/tag/v2.4.0)。

## 本版变化

用像素图标和逐格进度串起导航、任务、计时与统计，保留中文可读性和准确数值。今日目标、关于、新建任务和计时调整页一起整理布局；任务总览与管理合并，极简模式入口和统计面板也采用同一套样式。

建筑记忆直接在原工作台中展开，不再叠加新面板。可继续任务与纪念建筑都铺满世界和导航之间的区域，压缩重复信息，让摘要和继续按钮在手机竖横屏中完整可见；关闭或继续时保留当前镜头。

统计热力图放在顶部，采用像素点阵和四档时长：0–3、3–6、6–9、9–12 小时；无投入的日期留空，超过 12 小时沿用最高档。点选一天或按住拖选连续多天，上方摘要和下方任务时间团簇随选中范围一起更新。有效轮次与累计每日目标放在一起，删除重复日期输入、快捷范围和页尾说明。

修复 Litematic 负方向选区被误当成镜像的问题，保留方块本身的朝向与实体坐标。补充蓝图中的仪式剑和昔涟手办同步修正，原有名称、类别和数量不变。已有任务的建筑快照不自动改写；以前倒置的手动蓝图请重新导入。月湾画廊仅用于本地验证，没有封装进 App。

换上确认的切面像素番茄钟图标：红色果皮包住凹入的浅色表盘，Android 与 PWA 共用母版。

新安装默认使用海洋小岛、精致光影、系统主题、当前施工轮廓和 100% 沉浸玻璃；自动连续专注、专注完整性与极简模式默认关闭，返回专注提醒默认开启。已有用户保存的设置不改动。
