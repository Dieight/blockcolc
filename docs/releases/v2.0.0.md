# 方块钟 v2.0.0

## 本次更新

v2.0.0 是从 v1.11.0 之后的一次完整产品升级，重点覆盖专注流程、页面结构、世界渲染、本地数据和 Android 生命周期：

- **专注与恢复**：普通任务、习惯任务、固定轮次、按结束时间排程、马拉松和极简模式统一时间真相；支持休息、待继续、提前完成、中断恢复、自动连续专注和统一汇报，跨后台、锁屏和进程恢复继续依赖持久化绝对时间。
- **极简模式**：空闲显示当前时间，滑动选择结束时间，专注/休息显示真实状态；今日专注时间轴可左右切换，保留键盘等价操作和完整模式返回路径。
- **统计与任务**：新增本地成就墙和历史解锁提示，重做统计图表、任务分配、纪念建筑和小任务时间分布；建筑记忆成为继续任务的入口，保留未可追溯历史的诚实标注。
- **界面与交互**：设置页改为分组列表和可调液态玻璃，统一浅深主题、触控命中区、焦点、中文输入法和大字号布局；Android 返回键支持覆盖层逐层退出，提示、动效和导航状态更一致。
- **世界与渲染**：扩展自然山谷、经典空岛和海洋小岛的地形、岛屿、海峡、雾、光照、日月和环境装饰；修复海洋接缝、建筑地基、道路/路灯融合、树木碰撞、云层和建筑预览问题，并降低无关操作造成的世界重建。
- **蓝图与材质**：增强 Litematic 导入、预览、保存快照、60×60×60 级别建筑边界和本地备份恢复；资源包支持更完整的 Java 26.3 方块状态、模型、纹理、染色、动画、透明几何与安全回退路径。
- **Android 生命周期**：加入注意力状态机、标准后台休息倒计时、到点通知、系统返回和通知权限失败边界；避免重复通知、后台逐秒循环和恢复时覆盖用户数据。
- **现实天气**：可选接入和风天气定位与实时天气，位置只保存在本机；未开启、未定位或请求失败时继续使用本地天气。世界面板每次冷启动显示一次当前天气提示，保持原位置、5 秒停留和淡出动画。
- **蓝图与内容**：补充内置建筑与奖励内容的标题、描述、分类和稳定标识，保留原有简要描述。
