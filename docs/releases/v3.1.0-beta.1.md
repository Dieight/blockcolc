# blockcolc v3.1.0 Beta 1

- 流畅画质调整了地表拼接，减少旋转时出现的白色闪点。
- 专注中返回 App 时优先恢复计时，复用已加载的世界。
- 在观看设备尝试开始专注时，普通和极简模式都会提示如何把本机改为执行设备。
- ColorOS 流体云恢复 2.9.0 的番茄图标。收起后显示「专注中」「休息中」或「等待中」。
- 打开分享每日时长的好友卡片时，默认显示今日专注，可切到总计。

本版也包含计时、任务、统计、设置和好友界面的返修。[PR #2](https://github.com/Dieight/blockcolc/pull/2)

Android 构建号为 113。可在设置中加入 Beta 通道，或从 GitHub Releases 下载 APK。[Beta 1 发布页](https://github.com/Dieight/blockcolc/releases/tag/v3.1.0-beta.1)
