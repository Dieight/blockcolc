# Blockcolc v2.1.0

2026-09-30 已发布：[GitHub Release](https://github.com/Dieight/blockcolc/releases/tag/v2.1.0)。

本版改善了世界画面与专注流程：日出日落和月相参与光照，夜晚亮度更一致，建筑阴影恢复；雨雪、雷暴、云、雾与极简信息面板的天气反馈得到增强。原创方块静态形状、环境装饰和资源包远景采样也有扩展。

专注方面，结算统一在沉浸页面，后台自动连续专注和休息提醒的状态衔接得到修复；极简选时边界、轮次阻尼、取消整项计划及冷启动镜头揭示已加入。资源包冷启动与提交推进做了有界优化，三张初始建筑补齐上层侧面。

已知边界：天气表现仍会在下一版继续小幅打磨；不同设备的 OEM 常驻通知、后台调度及真实定位需要继续观察。原创材质覆盖不等于 Minecraft 全部方块逐像素等价，低内存设备和极大项目的性能也未作普遍保证。
