# Blockcolc v1.11.0

V26 让打开应用、切换页面、回到世界和交付 Android 版本更快、更确定，并收口近期 OnePlus 真机反馈。

## 主要变化

- 计时、任务、统计和设置在冷启动期间并行准备，页面常驻后切换不再重复挂载。
- 降低无关 UI 操作触发的世界重建，并提取可确定性测试的指针、帧调度、地形 profile 与共享网格边界。
- 修复“重置地图”、海洋道路与路灯高度、马拉松习惯轮次初始化、习惯任务马拉松计时和取消计划回退。
- 专注与休息使用互斥的 Android 实时倒计时通知；折叠态缩短为“专注中”，采用纯白镂空番茄图标，并消除重复生命周期更新导致的闪烁。
- Android 注意力状态机把通知栏停留与后台往返各计为一次；新增有效离开后恢复原有世界内五秒提示。
- 撤回价值与马拉松计划重叠的“今日下一步”，并安全忽略短期测试版留下的对应字段。
- 发布流程拆分为完整门禁、不可变候选安装、用户验收和上传；候选、GitHub 下载件与真机安装逐边界校验 SHA-256。

## 已知平台边界

- OnePlus / OxygenOS 的通知抽屉能正确显示系统倒计时；当前息屏流体云模板只读取图标和两行状态，不读取 Android 标准 chronometer。应用不会通过后台逐秒重发通知来伪造倒计时，以避免耗电和闪烁。
