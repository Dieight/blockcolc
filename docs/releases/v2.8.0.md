# blockcolc v2.8.0

## 本版变化

- 世界增加方块像素动物：山谷和海岸的牛羊猪马、河海中的鱼与各环境的鸟。它们会停留、变速、转向，偶尔跃水或起飞，轻点有小回应。
- 改进海岸、山谷和海岛地形的起伏、岸线与交界，减少远近景断层和水面叠色；山谷河岸恢复草地与岩石。
- 减少地表查询、场景恢复和建筑几何的重复工作，调整缓存、后台准备与资源保留，改善世界重建和旋转表现。
- 整理任务与设置页面、折叠层级和便签，改进普通／极简模式的轻量切换与弹出页面动效。
- 修复中文中间插入、部分英文文案、计划恢复与自动续轮授权等问题，保留原有任务和专注记录。
- 改善夜间高通透玻璃的文字可读性，补齐习惯马拉松安排页的轮时长与推进说明。

## 已知限制

动物属于当前运行的装饰层，位置不跨启动保存；蓝图小预览不生成动物。使用自绘模型和贴图，不读取材质包的实体模型。减少动态时自动活动停止，仍可轻点回应。

ColorOS 的后台电池限制可能冻结应用；需要稳定后台交接时，可在本应用的系统电池设置中选择允许后台行为。应用不会自行修改系统策略。OriginOS 通知暂无对应真机的视觉验收。
