# blockcolc v2.6.0

发布日期：2026-10-08。Release：[v2.6.0](https://github.com/Dieight/blockcolc/releases/tag/v2.6.0)。

## 本版变化

普通与极简模式通过像素传送门切换：绿色空框作为入口，方块沿屏幕边缘逐一筑门，紫色涡旋衔接新画面；返回时紫焰等待世界准备，再以带火舌的开洞显露普通页面。转换不拉伸世界，也不重复重建；普通计时页移除重复的任务按钮，极简入口移到原位置。

结束专注、取消计划和多轮汇报统一使用可调通透度的液态玻璃。调整、关于、今日目标与新手教程使用上沿平直、左右下贴边的玻璃面板。设置选项增加平移反馈，导航、品牌与调整图标补充像素动效；热力图从全灰按日期扫成实际深浅绿色，选日不重复播放。

首次启动加入六页简要教程，覆盖任务、专注、世界、统计、习惯和备份，也可从设置重看。加载画面随机展示四款房屋风车或番茄生长循环，果实落地弹起后消失；减少动态时保留静态画面。

标准版支持 App 内更新：手动检查后确认下载，新增默认关闭的自动检查并下载选项。下载校验摘要、包名、版本与签名，再交由系统安装，不静默安装。

细化万象海岸的海床起伏、连片珊瑚与岸边过渡，减少水面和海底摩尔纹，清理冰刺区域旧树，补齐方块针叶林。保留已有建筑与地形身份。

整理冷启动、模式转换与施工轮廓切换：复用渲染资源，轮廓增量切换，真实绘帧和 GPU 准备留在加载阶段。修正任务展开图标位移、滑杆上拉轨迹和选时停顿；遇完整轮次的停顿调整为 500ms。已有任务、设置与建筑记录不重置。
