# blockcolc v3.1.0 Beta 11

- 全面消除手势冲突：移除 3D 世界上的滑动切换建筑（含极简模式）、时钟横向滑动切换计时模式，以及任务页滑动切换大任务，保留顺滑的跨页横滑与自由 3D 视角旋转；大任务切换统一保留顶部标题弹窗与任务页 `<` `>` 切换器。
- 还原画廊级世界过渡与计时页构图：移除 3D 世界与下方工作台之间的硬切分隔线，加入 84dp 柔和渐隐过渡幕布、无框漂浮世界标题与深浅背景自适应状态栏文字；计时页回归左对齐建筑排版，上方以无文字动态双细线轻点切换固定轮次与结束时间，下方采用双栏无卡片细线规格条（左侧当前推进 + 16 格微进度条，右侧日期倒计时或未开启时自动轮换的中外惜时名言）；主操作按钮加入按压/点击从炭墨扫向松绿的幕布动效。
- 修复任务页多任务切换缺陷并升级交互式径向点阵雕塑：按文档稳定顺序遍历全部大任务，修复 3 个以上任务时 `<` `>` 仅在两项间来回切换的问题；移除大任务标题旁易误触的展开箭头与二级目录；将进度圆盘升级为 6 环 26 点圆形磁性点阵雕塑，支持按住拖动吸引形变与轻点松绿涟漪波。
- 统一像素图标笔触并升级底部导航动效：将全套 12×12 像素图标（含信息说明、展开、加减、搜索、好友等）统一为一致的 1 格建筑细线视觉粗细，采用新版「任务」三行实心点阵与对称八齿「设置」齿轮及对应微动效。
- 细节精修：加大设置页六大分组标题字号与段间留白（带松绿竖标）；无卡片物理滑杆补齐端标、虚线牵引、松绿弹跳尾迹与微音效；统计热力图补齐柔和的 26 周低对比空白网格底纹；升级建筑落成弹窗、成就解锁弹窗与顶部画廊展览提示条，同步更新新手教程文案并加入遵循系统静音/触感设置的高克制微音效。

Android 构建号为 123，可覆盖更新。
