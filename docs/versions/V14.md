# V14 Work Packet

Status: workflow preparation complete; product feature scope is not frozen.

V14 currently improves how changes are defined, tested, measured, and released. It does not change the Android version or publish a Release.

## Non-goals

- No V14 product feature is silently added by this workflow work.
- No forced CI provider, issue tracker, cloud service, account, or release bot is introduced.
- No real user blueprint, resource pack, signing credential, screenshot, or private report is added to the public repository.
- No debug-signed APK is published.

## Gate Matrix

| Change risk | Required checks |
| --- | --- |
| Documentation only | Markdown/link scan and version check |
| Domain/UI narrow change | version check, typecheck, unit tests, affected E2E |
| Storage, timer, renderer, or shared workflow | full unit suite, low-concurrency full E2E, Web build, Android JVM/Lint, formal APK |
| Release | Prepare evidence, explicit publish confirmation, remote redownload hash/cert check, connected-device install when available |

## Open Decisions

The next product feature set, schema impact, and V14 user-facing release scope remain open until explicitly confirmed.
