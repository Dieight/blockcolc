# V18 Work Packet

Status: prepared for release as `v1.3.2` (`versionCode 18`) on 2026-08-14; release gates and published-artifact verification pending final user authorization.

V18 removes the remaining "AI-flavored" UI: the interface should read like a quietly designed Android utility, not a generated dashboard. Secondary actions become text buttons, stacked cards are reduced to the useful ones, typography follows the Android-settings hierarchy, and the timer tab must feel instant even while the voxel world rebuilds.

## Data and compatibility

- No domain schema change. Epoch caching changes only the projection-copy contract: `snapshot()`, `activeProjectProjection()`, and `worldProjection()` return shared per-epoch copies that consumers must treat as read-only (the voxel renderer re-validates blueprints into new objects).
- The notification settings jump is a new Capacitor plugin registered in `MainActivity`; non-native platforms return `false` without touching the bridge.

## Non-goals

- No UI library, no new card stack, no streak or leaderboard language.
- No permanent render loop or preloading of the voxel renderer in the background.
- No version bump or published Release during ordinary V18 implementation; release is prepared only after explicit user approval.

## Acceptance

- Settings, tasks, statistics, and creation pages keep 44px targets and readable hierarchy across `360x800`, `412x915`, `915x412`, `768x1024`, `1440x900`.
- Tapping 计时 from any tab paints the loading page in the same frame instead of stalling the source page; the world appears within a bounded rebuild and the page never hangs on failure.
- The candidate APK matches its SHA-256 at build/copy/install/redownload boundaries and preserves app data on the authorized OnePlus PJX110.
