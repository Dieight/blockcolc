- 新增 RenameQuickNote，保留 ID、创建时间与完成状态；双击正文编辑，Enter/F2 可用，Escape 取消。

- 原五项审计修复一并保留；补上重启后无法写 UI 清理状态时也先撤销旧原生续轮授权的边界回归。

## 便签性能对照

`notes-performance.json`：同一 Chromium、同一 216000 体素合成世界，交替执行 4 次原整状态保存和便签切片保存。中位数 976.9ms → 461.1ms，降低约 53%；最终世界体素与便签核对一致。此数值只代表 IndexedDB 保存路径，不代表整机体验。

`notes-ui-feedback.json`：双任务合成界面中，新增、修改、完成、删除从输入事件到 DOM 反馈分别为 6.9 / 5.2 / 5.7 / 2.8ms；两次 animation frame 后为 80.2 / 37.2 / 62.8 / 34.6ms。该浏览器测量不等于物理屏幕呈现时间。新增、修改、完成的持久化 UI 更新分别为 39.0 / 36.8 / 87.2ms；删除的持久化已由浏览器回归核对，本诊断未单测其完成耗时。最初诊断误以为删除后仍存在 pending 行，超时记录保留于 `notes-ui-feedback.log`，修正观测条件后的诊断退出 0。
