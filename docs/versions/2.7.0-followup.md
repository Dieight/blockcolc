## 采样约束

已执行样本的授权来自此前已备份 OnePlus 的实验请求，性能对照沿用旧基线。诊断只记录有界数值与代码栈；合成专注在隔离复制库中执行，恢复原库和设置，不把合成记录当作性能收益。现已按用户新指示暂停设备工作。

实机结果及限制见 [设备记录](../research/2.7.0-device-performance.md)，OriginOS 协议和版本见 [调研](../research/2.7.0-originos.md)。/73 曾完成构建，但未安装或上传；这次反馈后的交付另增构建号，不复用该包。
