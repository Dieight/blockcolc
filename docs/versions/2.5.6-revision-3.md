## 根因与改动

- 多轮恢复闪页及轮次丢失：局部计划先更新、父层业务快照后更新时，协调逻辑把已创建的新会话当成不存在。现在按服务的真实 revision 取同一批业务事实，汇报回执只冻结呈现，不冻结业务状态。
- 开始专注变亮：旧版开始专注效果直接把全世界曝光提高约 21%，持续 900ms；已移除，保留交付推进后的施工光反馈。转场也不再透出浅色背景。
- 每日档改为单份滚动合并根：不可变蓝图及记录分块仍按内容哈希复用；最新根校验及事务成功后再回收旧日档和无引用块。旧操作回滚、用户导出文件不受影响。
- 冷启动只渲染一次启动宿主，读取记录、环境准备、场景预热共享同一个加载动画。预热最远视图和目标视图后才计开场时间，不将预热成本混入动画首帧。复位清掉旧交互采样，开场动画不参与交互降档判断。
- 万象海岸按默认视角固定区域中心，不用扩张后的建筑均值移动九宫格。暖海采用半透明水面和海床；增加珊瑚、斑驳树及营地，土锥避让按真实地面支持判断。
- 奖励不再参与任务地面的整平约束；读取原地形支撑高度，用自身脚基补齐高差。选择奖励只改变镜头和简短日期卡，不改变当前任务。

## 原始失败与处理

- 地形连续性断言确实发现细峰噪声过密，调平细峰频率后仍按原 `<220` 跃迁上限验证，没有抬高阈值。
- 海岛土锥避让改变了不安全的村庄／树点，部分旧布局哈希失效。对比 HEAD 原规划，确认山谷主体与经典空岛未被误改、有效沉船保留后更新相应哈希；保留原始 [world-unit](../../artifacts/v256-revision3/world-unit.json) 与 [world-repair](../../artifacts/v256-revision3/world-repair.json)。
- 备份迁移新增测试的时间格式不符合领域校验，修正合成夹具后 [44/44](../../artifacts/v256-revision3/storage-unit-final.json) 通过；原始 [storage-unit](../../artifacts/v256-revision3/storage-unit.json) 保留。
- 浏览器早期失败包括隐藏时钟未准备好、减少动态下期望旋转、把球静止后的百分比 CSS 值当像素，以及普通模式误期望通用轮次标题。极简曝光补测需请求中性绘帧：取消脉冲后静态世界会正常停止绘帧。修正这些测试条件，不改变产品预期；原始 [ui-focused](../../artifacts/v256-revision3/ui-focused.json)、[browser-verified](../../artifacts/v256-revision3/browser-verified.json) 与各次亮度批保留。
- 万象海岸的输入记录确认 SwiftShader 首个拖动帧间隔约 4.3 秒，超过既有 2.5 秒防丢触摸兜底，后续鼠标移动已没有所有权。最终诊断只在明确的软件 GPU、超时及所有权已释放条件下，使用同一批合成指针输入核对真实渲染的复位；不修改生产兜底，不称为手机手感验收。见[原始输入审计](../../artifacts/v256-revision3/mosaic-gpu-input-audit.json) 与最终报告附件。
