### 2026-11-16：新界面的 OnePlus 整体对照

本轮原库只读核对为 24 项任务、500 条历史；恢复和密码文件的私有副本均留在 D 盘。计时测量使用单独的 23 项任务、442 条历史、16,153,090 字节原备份副本，避免把合成或旧副本上传真实账号。每组结束核对原库事实及受控文件，恢复原 /11 主包与测试包；正式 App 摘要不变。用户更新 OnePlus 后，新应用可能需手动输入安装密码，后续复用现有包名与签名覆盖，不另建实验身份。

- [独立 CPU／系统归因](../../artifacts/experiments/v3.0.0/p4-ui12-performance-20261116/oneplus-profile-r2/result.json)：未采样运行的世界打包约 1.86 秒。单独的 10ms ART 栈与 SurfaceFlinger 时间线用于定位，不混入冷启中位数，也不把内联后的单个 Native 方法名当作精确成本。原始 trace 在 D 盘。
- [现有 /104 对照包](../../artifacts/experiments/v3.0.0/p4-ui12-performance-20261116/oneplus-ts-existing-r1/result.json)：没有安装、重设数据或开启 CPU 采样。核对同为 23 项任务／442 条历史、海岛 V4 同种子、精致档、普通模式、本地天气，五次进程冷启的世界观察中位数为 3.68 秒。其 CDP／宿主观察包含传输开销，不与 Android Fully drawn 或 GPU 栅栏混记；旧的采样冷启记录不作这一组基线。
- R3 的循环及分配优化通过 [27 项定点](../../artifacts/experiments/v3.0.0/p4-ui12-performance-20261116/spatial-units-r3b.json)，包括角点包围盒 oracle、最近命中、大扫描取消、现有雨雪数据和工作队列退出。对照未证明大幅提速，仍需继续优化。
- R4 将静态地形／景物、动物碰撞和雨雪地表的独立准备重叠，最多两个辅助线程；建筑及实体仍有单一编译器，外部材质暂保留顺序准备。每批必须等子任务实际退出后才复用或清理。字节、材质、相机、所有者复用和失败退出的 19 项定点通过（初次相机误用对象身份比较，修正为实际元数据后补验）。OnePlus 打包约降至 1.01–1.17 秒，但完整世界前三次仍约 3.7 秒、后两次约 3.0 秒，未达到 P4 冷启目标。

R4 继续暴露两项采样准备问题：统计日历通过可访问描述提供名称，旧观察器误找文字；应用的基线编译配置没有覆盖新静态编译器与渲染初始化，且应先确认基线已安装再请求 profile-guided AOT。观察器及配置正在补正，下一组同时记录实际编译状态、完整世界与稳定帧。尚未判定 P4 通过，用户候选 /12 未交付。

### 地形与渲染包的 OnePlus 对照

两版均为同一 OnePlus、23 项任务及 442 条历史的海岛场景，精致档，固定 15:00 晴天。按设备时钟测五次冷启动，原生均确认地形和景物缓存命中，旧版均确认场景及建筑缓存命中。原生首个完整世界 SurfaceView 呈现中位数 **2.488 秒**。旧版观察到加载界面的最后一笔读数中位数为 **3.513 秒**，读到世界准备完毕后的首个应用窗呈现中位数为 **3.689 秒**。以较早的时间作下界，原生至少缩短 **29.2%**。新旧界面使用各自的正式视口和开场镜头。失效重建另测。[两版数字及缓存状态](../../artifacts/experiments/v3.0.0/p4-ui12-performance-20261116/oneplus-clear15-surface-r9c/paired-cold-assessment.json)

原生较上一组的静态地形／景物打包中位数由 682 降至 605ms，整个世界打包由 992 降至 905ms。三页回到计时并观察到世界可用约 515–680ms，含转场。在同一世界连续六次旋转，251 个显示间隔的 P95 为 41.72ms，最长 50.06ms。Home 后返回观察到世界可用为 108ms，世界区域尺寸匹配。[原生冷启动与交互记录](../../artifacts/experiments/v3.0.0/p4-ui12-performance-20261116/oneplus-clear15-surface-r9c/assessment.json)

### 2026-11-17 缓存失效与实际拖动

沿用 OnePlus、23 项任务、442 条历史、海岛种子和晴天 15:00 精致档。五次原生冷启各用全新派生目录，回执均为地形、景物重新生成，建筑几何没有缓存命中。旧版在隔离实例中每次只移除对应环境的两份派生缓存，五次都确认失效。原生完整世界实际呈现中位数为 **4.361 秒**，旧版为 **7.377 至 7.525 秒**（最后一笔加载状态至就绪后的首个应用窗呈现）。按旧版较早边界计算，原生至少缩短 **40.9%**。两版使用各自的普通计时视口。 [原生五次](../../artifacts/experiments/v3.0.0/p4-ui12-performance-20261116/oneplus-rebuild-island-r10/result.json) · [旧版五次](../../artifacts/experiments/v3.0.0/p4-ui12-performance-20261116/oneplus-ts-rebuild-island-r10/result.json)
