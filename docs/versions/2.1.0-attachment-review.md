# v2.1.0 天气补丁与真实天文方案审查

## 结论与采用范围

三个附件按候选实现/设计理解，不直接视为仓库规范或发布授权。
原件保留在用户 Downloads；实现调整当前所有者，不创建第二套天气系统。

- 第一份 precipitation patch：采用低档可见粒子下限、稀疏玻璃水滴、停驻后慢滑、克制高光、隐藏/减少动态行为。
- 第二份 perceptual mapping patch：采用 kind 感知投影与事实分离、视觉强度共享、弱雨不过度压暗云层。无行号 `@@` 不能直接应用。
- 真实天文方案：采用地点、季节、绝对时刻驱动太阳/月亮与事件缓存；保留离线/空事件回退，放弃附件中要求直接发布/PR/真机验收的步骤。

## 天气冲突修正

两份补丁重复修改相同链路，第一份标量曲线把零降水变为无雨，第二份明确按 rain/snow 分类保留小下限。
最终约定：真实降水量原值保存；若已确认 rain/snow，数值取整为零也能有稀疏可见粒子；clear/cloudy/mist 始终不产生降水。
感知曲线只在 voxel 投影计算一次，世界与面板共用，不在 QWeather 适配器里再增强一次。
粒子先按质量缩放，再应用有限可见下限，所有数值校验非有限输入，预览采用独立数量和空间预算。

玻璃水滴不挡输入，不持续产生大颗白点；生成、重力、终端速度与拖尾有上限。
暂停/隐藏时停帧，恢复不会通过巨大 dt 瞬间冲走所有水滴；减少动态只保留少量静态滴。

## 天文修正

- 固定 SunCalc 2.0.2，使用其 ESM/类型声明；2.x 是度数、北基准顺时针，不能套用 1.x 南基准弧度转换。
- 世界北方固定为 -Z；相机旋转不改变太阳方向，天气只调制光量。
- SunCalc 高度已包含折射。真实太阳直射从表观视盘上缘过地平线附近开始；不重复用几何 -0.833° 补折射。
- 太阳落山后不保留强伪太阳直射来抬亮夜间；夜间可读亮度归环境光与曝光，月相只做无新阴影灯的克制增强。
- 暮光按太阳高度正确归档：0 至 -6° 民用，-6 至 -12° 航海，-12 至 -18° 天文，低于 -18° 夜间；晨/昏为靠近地平线的细分。
- QWeather 日历用于事件与缓存覆盖；连续位置/月相由本地历算，不在两个来源之间跳动。
- API 日区间必须是带时区的 epoch；不假设一天恒为 24 小时，不把当地日期字符串当 UTC。
- 极昼/极夜的 null 事件合法；坏字段可局部置空，缺少可用区间才拒绝整日。缓存新鲜度与覆盖分别检查。
- 天气与天文有独立取消身份，共享定位 single-flight；禁止新天文调用取消天气调用。
- 已授权缓存坐标可在 API 失败时本地计算；关闭现实同步时立即停止采用坐标并清相关缓存。
- 可见时每 30 秒取样，恢复首帧立即校正；不依靠启动后累计时间，不重建世界、图集或物体。

依赖许可随应用提供：[SunCalc 声明](../../apps/web/public/licenses/suncalc.txt)。

## 验证边界

实现由本版工作包追踪，不能把附件自带测试方案当已通过。
需覆盖微量/零值分类、低档缩放、玻璃暂停与触控、坐标角度、暮光边界、月相、极区空事件、时区/跨日、缓存与双请求并发、开启/关闭调试恢复。
浏览器模拟不能证明 OnePlus 常驻通知、真实定位权限或原生 HTTP；这些保留真机专项验收。

研究来源：[QWeather 日预报](https://dev.qweather.com/en/docs/api/weather/weather-daily-forecast/)、[SunCalc 发布](https://github.com/mourner/suncalc/releases)。
