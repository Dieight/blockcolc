## 当前进展

### 45 号包反馈

- 普通开场只移动了相机，未同步建筑焦点与缩放限位。现在使用真实建筑聚焦规则收尾，只设置镜头焦点，不打开记忆；右上角地图按钮回到聚落，旋转/缩放/重排不再套用旧的全景限位。
- 深色通用 input 规则覆盖数字输入的透明背景和边框。数字控件不再走这条兼容规则；保留编辑态和键盘焦点反馈。
- 降水反例固定了普通短画幅、极简长画幅、四个正方向和近远缩放。同一场雨在两个覆盖面积相差约四倍的视野中仍绘制 1296 个粒子；改为按覆盖体积调整 draw count，实例缓冲只上传一次。雨雪使用地表高度纹理，从山坡上方落下，避免大部分远处粒子在山体内部被遮住。纹理由世界重建生成，旋转不做 CPU 地形碰撞或实例改写。
- 沉船反例在 `archipelago-230` 的 32 栋聚落缺失。原因是旧搜索半径仍在扩张后岛内，不是老存档持有一艘被 LOD 压扁的船。扩大岸线搜索只用于原搜索失败的情况；已有有效海岛落点、空岛与旧山谷摘要保留，v4 山谷摘要随获准的细节范围更新。
- 第一轮门禁的扩展检查发现 30/60/100 栋山谷超过原有网格预算。远景细带原本比中景更密，扩大范围后放大了这一成本；改为延续中景 4 单位格，近中景扩大范围和外侧 8 单位格保留。原有 15 万格/50 万三角形上限没有上调；三个大聚落预算和六组装饰摘要重新通过。
- 第二轮业务批次检出分配图的无障碍名称缺少实际时长，现已包含任务名、时长和比例。离开提示测试也补逐次保存确认，保留真实 3.2 秒离开和 5 秒提示淡出；相关三条重验通过。两轮失败不算完整通过，详见 [46 号工作包](V46.md)。
- 第三轮业务批次 56 通过、1 跳过；视觉批次 71 通过、2 失败。分配图旧柱状结构断言改为 L14 点簇、准确图例和十种布局；建筑记忆先等开场完成或导航取消，再复位并核对全景限位。分配图通过，记忆六条移动/桌面回归通过；失败和重验记录见 [46 号工作包](V46.md)。
- 第四轮门禁全部浏览器批次结束，207 通过、13 失败、3 跳过，未出包。剩余测试明确区分开场聚焦和全景，等首个有效帧后再检查环境运动；相机与环境相关七条定点通过。真实颜色绘制仍超预算，实测主要开销来自地形而非导入模型；现将完整相邻共面矩形合并，保持地形细节和世界坐标 UV。树林分块裁剪且共享遮蔽数据；压缩网格沿用有界缓存。新增纯回归 11 条与渲染八条通过，原预算和阴影要求未放宽。接下来用新冻结输入跑完整门禁，本轮 APK 尚未完成。
- 第六轮完整门禁 219 通过、1 失败、3 跳过。降水运动测试仍默认开场处于全景，近景山坡挡住稀疏雨点，使两张截图相同；shader 实际时钟在更新，延长窗口也复现。现保留近景触控检查，明确回全景验证真实像素运动，并增加实际 shader 时钟断言；连续三次通过。只修改测试观察条件，应用降水密度与调度不变；最终完整门禁和 APK 仍待完成，记录见 [46 号工作包](V46.md)。

## 关键变化

边缘扭曲先撤回。六张参考用于通透度、背景散射、明暗和边缘高光，不默认重新启用扭曲。若以后尝试更完整折射，先检查真实快速旋转和减少透明度路径，作为另一次明确采用的方案。

性能先定位重复重建、解码/图集上传、深度绘制、主线程长任务和帧调度。Rust/Wasm 是测出 CPU 热点后可考虑的实现选项，不在定位前重写技术栈。

参考截图属于本地用户资料，位于 `liquid_glass/`；不作为可分发 UI 素材，也不修改或删除原件。
