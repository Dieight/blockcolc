### 2026-10-26：镜头雾距与共享运行参数

审计确认，独立环境采样仍带世界首次准备的镜头距离，而后续缩放只更新投影。这会使近远雾范围停在原值。现将廉价的镜头计算拆为 `NativeFogProjection`，只包含天气种类和地形／建筑范围，保留环境提供的雾色。准备、缩放及采样采用共用正式范围公式；即使有效天气样本生成早于手势，也使用绘制线程最新距离。过期样本仍按场景及版本拒绝。

### 2026-10-26：逐材质颜色、雾色与源像素对照
