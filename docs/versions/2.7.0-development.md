## 关键变化

派生缓存与业务数据库、备份分开。旧缓存、容量不足或读取失败均回到确定性生成，不影响任务保存。页面与每日备份共用低负载调度；设置保存与画面采用分开，隐藏世界只保留最新快照。

旧的设置页场景等待器及无人使用的回调已由世界宿主的延后采用流程替换，不保留两套准备入口。重设置准备失败有重试入口；离开后再返回仍会补齐呈现准备。

收尾审计补齐了两个返回边界：冷启动预热在后台中断不再误报就绪；隐藏期间任务变化先在加载层下采用，再绘制最新画面，无论是否同时更改画质。GPU 准备失败会露出重试入口，不留在全屏遮罩下面。可见时的普通推进仍使用原提交回执。
