## Data and compatibility

- SW-01 changes only renderer lifecycle, not state. Epoch-cached projections stay read-only shared copies; the resident renderer must re-resolve packs/worlds via the same projection path.
- BL-01 is display-only; the stored blueprint snapshot and its id are untouched.
- MT-01/02 do not change backup or resource-pack manifest schema; compatibility summaries remain projections.

## Non-goals

- No cloud sync, no streaks or shame language, no leaderboards.
- No continuous render loop, no background rendering while the timer tab is hidden.
- No shader-pack execution (Open/Iris packs stay non-executable per V5 decision) and no third-party pack redistribution.
- No version bump or published Release during ordinary V19 implementation.

## Acceptance

- Switching 任务↔计时 shows the world in the first frame (burst evidence), and cold start still shows the unified loading page exactly once.
- On-device A/B pixel diff proves a fixture pack changes the visible world; switching back restores the original appearance.
- Renaming an imported blueprint label updates the world building-details text without touching progress or the stored snapshot.
- Starting a focus round shows the V18-grade immersive UI on-device; natural completion/early completion/interruption flows keep their existing behavior and E2E coverage.
