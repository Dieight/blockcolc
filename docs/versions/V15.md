## Compatibility

- Existing preferences with `visualExperiment=water` or `mist-beam` migrate to Cinematic; missing or disabled legacy values migrate to Auto.
- This is a local UI preference and does not alter the domain schema, backups, tasks, blueprints, terrain seeds, or building progress.
- Low-capability devices may resolve Balanced or Cinematic requests to Performance. The stored request remains unchanged.
- Construction-outline visibility is a local UI preference, defaults to the active building only, and does not alter domain schema, backups, task progress, or existing imported blueprint order.

## Non-goals

- Do not copy, bundle, execute, or redistribute IterationRP, Iris, OptiFine, or other shader-pack source/assets.
- Do not add path tracing, temporal accumulation, screen-space reflections, deferred rendering, WebGPU-only behavior, or a continuous animation loop.
- Do not change the public version until V15 is grouped into an explicitly approved Release.
