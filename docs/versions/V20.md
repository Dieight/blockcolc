# V20 Work Packet

Status: implementing 2026-08-17. V20 is the hand-feel and living-world release: the Pomodoro core gets micro-motion, and the world starts breathing.

V20 polishes the timer itself (micro-animations, press feel, transitions) and makes the world feel alive: leaves sway, clouds drift, and buildings assemble block by block after focus rounds and during breaks. No haptics, no UI breathing effects, no agent-facing features (dropped by owner decision).

## Contract change (approved by owner)

- Old (V3): no continuous render loop; frames only during interaction.
- New (V20): ambient loop allowed while visible + foreground (cloud drift, leaf sway, construction reveals); setVisible(false)/background stops it. Interaction rendering unchanged. Battery: performance tier disables ambient animation; cinematic/balanced use a minimal per-frame update set.

Implementation note: the loop is a 100 ms throttled interval pump (like the existing rain pump), not a 60 fps rAF loop, so `continuousRendering` remains false and idle cost stays minimal while the same visual contract is honored. Ambient renders share the single rAF slot with interaction frames and are adaptively throttled: the next ambient frame is only requested after the previous one finished and an interval elapsed that scales with the measured frame cost (250 ms fast devices → 1 s when a single cinematic frame is expensive), so a slow GPU can never turn the living world into a pipeline-saturating loop (this is what kept Playwright canvas screenshots stable under software WebGL + bloom).

## Data and compatibility

- No state, storage, backup, or import/export changes. The world grows from the same projections as before; only the presentation timing changes.
- The reveal building renders through the per-instance fallback path while revealing; the next rebuild re-batches it into the merged atlas path.

## Non-goals

- No haptics/vibration, no UI "breathing" effects.
- No agent-facing features, no new import/export or sync paths.
- No new world content systems (leaves/clouds/buildings render the same data; only motion is added).
