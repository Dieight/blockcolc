## Redmi 复测

保留 Redmi 原有数据和画质，从任务、统计、设置各返回计时两次。改前与改后每次返回窗口帧耗时的 P95 中位数约为 64.1 → 46.0 ms，超过 32 ms 的帧从 107/500 降至 79/564。改后最长一帧约 146 ms，较旧设备仍可能偶发卡顿。

Perfetto 可用轨迹中，改前最长的窗口缓冲交换为 103.1 ms，其中 70.4 ms 和 Filament 的缓冲交换重叠。改后可见最长交换为 88.5 ms，仍有 67.0 ms 重叠。轨迹有解析警告，时序用于定位窗口与世界绘制争用，性能统计以同机窗口帧记录为准。原始记录在本地 `D:/blockcolc-android/performance/v3.0.0-112-route`。

测量时的 /112 已使用最终的计时与世界调度代码。最后构筑还修正了切口 API 的版本检查写法及云条款的读取状态。Redmi 随后覆盖安装[最终签名 APK](../../artifacts/apk/v3.0.0-112/redmi-final-install.json)，UID 和首次安装时间不变。应用进程已退出，手机保持锁屏。
