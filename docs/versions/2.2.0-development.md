## 冻结契约

- 天气、天文和腐败领域事实不被视觉演示或调试改写，专注和统计计时不依赖天气动效。
- 拖动是有效交互，不是隐藏/后台；降水时钟只按实际可见性和减少动态暂停，恢复不补跳。
- 全模式共用结算业务，极简只调整展示。保存失败保持原报告及轮次分配，不清空或重复记账。
- 用户已确认雨为方块像素+层次、雪为细像素+层次；积雪分薄、矮、中、高四档，按原始归一化降雪强度非线性选择。共享视觉强度仍负责粒子可见性，不建立第二次雨雪感知重映射。
- “装饰”包含群系、地貌、村落和遗迹；用户已确认原型并采用：山谷和海岛各一处背景村庄，较原型再推远，空岛不生成村庄。不围一圈、不参与任务/统计/建筑记忆；其余结构的位置和大小由 root 决定，无需再次询问。花树只是该系统中的一层。
- 原版 JAR 可参考世界生成配置和测试既有资源路由，不新增打包原版素材或擅自改变许可。
- 所有新装饰沿稳定世界 seed 生成，不能跟着提交/切页随机重排，且需要实际远景轮廓验证。
- 本版按最新用户明确授权使用 TESTING.md 的测试后发布路径：新一轮完整冻结全量 + 成对包 + 用户反馈；不把 V43 或本版早期定点结果当作本轮完整门禁。
