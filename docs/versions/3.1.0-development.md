# blockcolc v3.1.0 开发记录

2026-11-24 从 v3.0.0 与界面返修合并提交 `e80b598` 开始。首个交付为公开 Beta 1。[界面返修 PR](https://github.com/Dieight/blockcolc/pull/2)

| 需求 | 实现 |
| --- | --- |
| 流畅档旋转时的地表亮点 | 保留原始不透明地表块边，沿用建筑与其他档位的现有几何优化 |
| 专注时从后台返回 | 未到截止时先记录应用切换，推迟首次每日奖励素材登记。只变更当前会话时复用世界、蓝图库和统计数据 |
| 观看设备开始专注 | 在普通、极简和计划确认中提示如何切换执行设备 |
| ColorOS 流体云 | 恢复 2.9.0 的番茄像素图标。收起状态显示专注中、休息中或等待中 |
| 好友分享的每日时长 | 展开时默认显示今日专注，支持切换到累计时长 |

公开 Beta 沿用正式包名和签名，版本名为 `3.1.0-beta.1`，构建号为 113。[Beta 1 发布说明](../releases/v3.1.0-beta.1.md)

Beta 1 从独立工作树构建时漏打包了账户服务的公开 CA 证书。Beta 2 将证书纳入源码，并在构建和验包时校验。构建号为 114。[Beta 2 发布说明](../releases/v3.1.0-beta.2.md)

Beta 3 加入像素光影档，计时页的极简入口与调整沿同一条右对齐线。构建号为 115。[像素画质与性能对照](../research/3.1.0-pixel-world.md) · [Beta 3 发布说明](../releases/v3.1.0-beta.3.md)

Beta 4 根据体验反馈撤回像素光影档，将已保存的像素档偏好读为纸雕。计时页保留两个按钮的右对齐。构建号为 116。[Beta 4 发布说明](../releases/v3.1.0-beta.4.md)

Beta 5 增加第三方接入令牌、好友授权读取和习惯建筑结算。本地备份补齐与云端相同的设置偏好。构建号为 117。[Beta 5 发布说明](../releases/v3.1.0-beta.5.md)

Beta 6 修正第三方接入在加载及显示令牌表单时引用的图标名称。构建号为 118。[Beta 6 发布说明](../releases/v3.1.0-beta.6.md)

Beta 7 修复极简冷启动时未开始计划的显示，补齐普通多轮计划的取消入口、签名包天气配置和令牌有效期排版。构建号为 119。[Beta 7 发布说明](../releases/v3.1.0-beta.7.md)

Beta 8 接入建筑和专注的分包同步，首次升级沿用原有本机基线。服务端保留旧协议入口，新旧客户端共用记录。补上增量摘要核验、离线开始时间投影和明确的设备接管。构建号为 120。[Beta 8 发布说明](../releases/v3.1.0-beta.8.md) · [分包同步 PR](https://github.com/Dieight/blockcolc/pull/4)

Beta 9 补过期好友状态、后台结束补传和旧库空闲投影，修复第三方接入表单和沉浸结束手势，加入轮次与休息到时闹钟。构建号为 121。[Beta 9 发布说明](../releases/v3.1.0-beta.9.md)

Beta 10 升级画廊建筑感无卡片 UI、直觉滑动计时与今日剩余目标磁吸、新增单体建筑叙事模式（建筑展台 / 真实天光双背景）并精炼工程、好友、统计与设置体验。构建号为 122。[Beta 10 发布说明](../releases/v3.1.0-beta.10.md)

Beta 11 消除 3D 世界、模式与任务页横滑手势冲突，补齐 3D 世界底部柔和渐隐幕布、左对齐双栏规格条计时页（日期倒计时 / 惜时名言轮换）、按钮黑转松绿扫光动效、修复 3+ 任务切换循环缺陷并升级圆形磁性交互点阵雕塑、统一全套像素图标笔触与任务/设置图标动效，同步精修设置分组层级、物理滑杆、落成/成就弹窗与克制微音效。构建号为 123。[Beta 11 发布说明](../releases/v3.1.0-beta.11.md)
