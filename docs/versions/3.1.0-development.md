# blockcolc v3.1.0 开发记录

2026-11-24 从 v3.0.0 与界面返修合并提交 `e80b598` 开始。首个交付为公开 Beta 1。[界面返修 PR](https://github.com/Dieight/blockcolc/pull/2)

| 需求 | 实现 |
| --- | --- |
| 流畅档旋转时的地表亮点 | 保留原始不透明地表块边，沿用建筑与其他档位的现有几何优化 |
| 专注时从后台返回 | 未到截止时先记录应用切换，推迟首次每日奖励素材登记。只变更当前会话时复用世界、蓝图库和统计数据 |
| 观看设备开始专注 | 在普通、极简和计划确认中提示如何切换执行设备 |
| ColorOS 流体云 | 恢复 2.9.0 的番茄像素图标。收起状态显示专注中、休息中或等待中 |
| 好友分享的每日时长 | 展开时默认显示今日专注，支持切换到累计时长 |

公开 Beta 沿用正式包名和签名，版本名为 `3.1.0-beta.1`，构建号为 113。[Beta 1 发布说明](../releases/v3.1.0-beta.1.md)

Beta 1 从独立工作树构建时漏打包了账户服务的公开 CA 证书。Beta 2 将证书纳入源码，并在构建和验包时校验。构建号为 114。[Beta 2 发布说明](../releases/v3.1.0-beta.2.md)

Beta 3 加入像素光影档，计时页的极简入口与调整沿同一条右对齐线。构建号为 115。[像素画质与性能对照](../research/3.1.0-pixel-world.md) · [Beta 3 发布说明](../releases/v3.1.0-beta.3.md)

Beta 4 根据体验反馈撤回像素光影档，将已保存的像素档偏好读为纸雕。计时页保留两个按钮的右对齐。构建号为 116。[Beta 4 发布说明](../releases/v3.1.0-beta.4.md)
