## 审查后实施契约

- 两个天气附件是候选代码，不连续 `git apply`。旧 scope 已过时，第二份含无行号 `@@`；按当前所有者合并。
- 原始降水数值不改变；雨/雪条件下允许数值四舍五入为零时仍用稀疏视觉下限，clear/cloudy/mist 不补降水。
- 感知曲线只在 voxel 天气投影计算一次，面板与粒子共享；低档缩放后仍保留有界可见数量。
- 天文复用现实天气开关与现有定位授权；关闭清除定位/天气/天文缓存，不增加后台定位或权限。
- 天气与天文独立取消身份，共享定位 single-flight；禁止新的天文请求取消现有实时天气请求。
- API 只持有事件日历；连续方向/月相由固定版本本地 ephemeris 计算，统一世界北方，明确角度单位。
- 使用带时区的 epoch 区间；空事件合法；API 离线但仍有获授权坐标时可本地计算；无位置回退现有本地光照。
- 天气只调制天文光量，不更改方向。30 秒采样只在可见时；恢复首帧立即校正，无世界/图集重建。
- 调试时间只影响世界，不影响专注 `endsAt`、统计日期、腐败事实、天气缓存或私有上传。关闭立即回投正常事实并短过渡。
- 所有动效有界且可被真实操作打断；减少动态/隐藏时不运行装饰性循环；重建加载先于世界过渡。
- 取消计划不虚增完整轮次，保存成功才清计划；中断耗时仍保留，计划取消与当前轮中断分开协调。
- 极简选时只补不足一分钟的量化空缺，不四舍五入吞掉休息或跨轮；阈值第一轮=专注，后续=专注+间隔休息。
- 原创覆盖按支持登记与代表性形状审计度量，“80%–100%”是目标，不用笼统百分比冒充原版等价。
- 26.3.jar 仅本机参考和测试，不复制分发原版资源；原创方块、世界装饰采用原创数据和现有合法模型路由。
