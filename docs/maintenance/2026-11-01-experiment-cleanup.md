# 2026-11-01 迁移实验磁盘清理

按用户要求，在冷启动实验前先清理 C 盘。本轮净腾出 **22,705,405,952 字节，约 21.1 GiB**；可用空间从约 3.2 GiB 回到约 24.4 GiB。数字来自清理前后磁盘读数，期间其他程序仍可能写入文件。

- 删除两个已停用的 v2.9.0 独立实验工程的构建中间文件，约 4.6 GiB。原始输入、源码、输出报告保留。
- 清除三个已在实验目录留存相同 SHA-256 的旧构建输出 APK，约 1.5 GiB。不是删除唯一历史包。
- 94 组、307 个历史 APK 路径中，将 213 份相同内容的副本改为硬链接。逐组回读摘要，原路径和字节保留；没有与 Gradle 输出共用文件内容。
- 核对两代实验目录原有 **15,209 个文件**仍在且长度一致；另核对当前预览 6 标准／私人包和两台设备的恢复基线摘要。
- 后续 P3 设备测试改用 `Save-ExperimentApk.ps1`，按 SHA-256 留存 APK 内容，再在每次证据目录建立原文件名。工具检查了重复目标拒绝、目录越界拒绝，以及模拟下一次构建改写输出不会改变既有证据。

本轮没有操作手机、应用数据、用户原件或正式发布目录。完整清单、脚本、执行日志和复核结果在 [本轮证据目录](../../artifacts/maintenance/2026-11-01-disk-cleanup/cleanup-verification.json)。首次去重脚本在祖先目录检查处循环，终止时日志为空，未改写历史包；修正后执行并完成上述复核。

硬链接只是同一份不可改写历史内容的多个入口，删去其中一个入口不会移除其余入口。需要独立修改副本时，复制到一个新文件再操作。APK 对象库位于 `artifacts/experiments/v3.0.0/apk-objects/`，不要直接覆盖其中的文件或已有证据路径。
