# blockcolc 视觉与交互

这里维护当前视觉和交互要求。产品行为见 [BLOCKCOLC](BLOCKCOLC.md)，实现职责见 [ARCHITECTURE](ARCHITECTURE.md)，操作检查见 [TESTING](docs/TESTING.md)。设计参考见 [来源记录](docs/assets/design-sources.md)，旧版设计保留在 [归档](docs/archive/v2.0.0/DESIGN.md)。

## 整体

世界展示用户的投入，计时提供下一步操作。首屏同时看见已有建筑和开始、继续或汇报的入口。文字平静、具体，区分任务进度和建筑风化。

世界使用原创或获授权的方块资产，许可与来源放在素材记录。UI 和世界分别使用语义色板；状态同时用文字或形状表达。世界 HUD 在明亮、夜间和天气背景上保持可读。

支持浅深主题，样式使用所属组件的语义 token，更新原样式。

## 文字和输入

- 界面用系统无衬线字体，计时用等宽数字。像素字体只用于世界标签，保留可分发许可与系统回退；字号按布局档位设置。
- 计时约 `56px`，紧凑屏可用 `48px`；屏幕标题 `22px`，分区标题 `16–17px`，正文 `15px`，元数据至少 `12px`。长任务名可占两行，计时变化时主要操作保持位置。
- 普通文字达到 WCAG AA `4.5:1`，大字 `3:1`；可见焦点至少 `2px`。玻璃统计标签使用高对比 token。
- 独立触控目标至少 `44 x 44 CSS px`，视觉小控件可扩大命中区，彼此不重叠；窄屏通过换行和重排保留目标大小。
- 支持 `200%` 系统字号、键盘导航、屏幕阅读器名称、中文 IME 组合和中间编辑。相邻重渲染保留输入框的原生组合文本。
- 分别处理减少动态和减少透明度；前者减少动画，后者使用可读的不透明表面。

## 页面和操作

主入口是计时、任务、统计和设置，世界/计时在首屏。首次创建按所选任务类型展示必填项。

每个状态有一个主要操作，次要操作弱化。沉浸和极简保留适用状态的返回路径。完成、中断和汇报有不同表现，结算仍按 BLOCKCOLC 的模式归属。

任务预览变化时保留输入。任务结构锁定后仍可重命名和排序，增删按原业务约束。删除、替换和恢复说明结果与恢复方式。统计无法追溯的归属标为未分配；成就何时提示见产品文件，展示 receipt 见架构文件。

## 设置与玻璃

设置使用分组列表卡，标题在卡片外，内部有语义分隔、选中、禁用和错误状态，分段控件与开关沿用现行样式。

数字值共用右对齐列，单位放在描述末尾。默认无硬框，编辑时出现柔和底色和可见焦点；普通字号列宽 `64px`，大字号按字形增宽、增高，完整显示合法数字。暂存、IME、提交与取消沿用原行为。

| 表面 | 材质 |
| --- | --- |
| 沉浸计时带 | 贴边矩形，使用本地 `0–100%` 玻璃偏好，只改材质 |
| 世界 HUD、坐标、建筑记忆和临时状态 | 固定高对比功能玻璃 |
| 设置卡片 | 固定浅深色玻璃，克制边缘和阴影，减少透明度时不透明 |
| 计划和任务选择 | 在内容之上的可读玻璃，焦点和选中清楚 |
| 正文、图表、输入、导航和破坏性操作 | 稳定的语义表面 |

计时带手机竖屏贴底，横屏、平板和桌面贴右。沿用平整延展轮廓，文字与控件在安全区内，世界可延伸到透明系统表面下。

玻璃折射从真实世界背景取四条窄边带，按边缘曲率偏移；中心透明、前景文字保持原样，天气与采样层不接管手势。采样失败用 CSS 玻璃，减少透明度时关闭采样。更新跟随世界帧，详见 ARCHITECTURE。

滑杆只控制沉浸计时材质，HUD 等玻璃保持自身样式。设置默认显示通透度数值，点击展开滑杆，键盘可展开和收起。

施工清单和大任务标题编辑共用右侧操作列，锁定说明在清单标题下面。

## 计时与极简面板

- 普通和极简共用计时、上下文与控件的位置。专注显示任务或轮次，建筑完成度留在相应建筑界面。
- 空闲沿用已批准的高面板，时钟与今日统计两页由面板内左右滑动切换；数字位置和面板高度保持原样。键盘左右键等价，纵向选时独立响应。
- 雨用方块轮廓、高光、轻重颗粒和不同滑落速度体现层次；雪用细像素点/雪花、远近速度和透明度。积雪按强度非线性分薄、矮、中、高四档，短面板同比压缩，四档仍可区分。
- 文字与手势在天气层上方，减少动态保留静态像素景。雨雪在旋转世界时继续落下，隐藏、后台或减少动态时暂停，恢复不追补。
- 今日图按小时分组，用 `15` 分钟方格表达真实专注区间。空闲留白，绿灰色区分任务与习惯，同一小时内不表示先后；图例和注释保留精确总量。
- 进行中的专注、待汇报和恢复错误先于空闲时钟显示。
- 极简汇报融入同一贴边玻璃带，以实际时长为主要层级，细分隔线分任务，轮次和进度操作沿用同一业务。说明默认折叠，报告可触摸滚动，主要提交可达。汇报可扩展高度，空闲两页高度保持原样。

动效用于反馈和空间变化，计时数字与主要布局保持稳定。动画结束或取消后仍能继续操作，减少动态路径同样可用。

## 世界与预览

自然山谷、经典空岛、海洋小岛保留各自轮廓、地形和建筑支撑。主要任务建筑是画面主体。山谷、海岛各有一处较远背景村庄，空岛省略；营地、残垣落在真实陆地，近岸沉船有可识别的水上船体和桅杆。树用方块组成，花成簇；远景保留结构轮廓。

相机使用旋转和有界缩放。构图依据聚落，裁剪覆盖可见地形，缩放极限仍保留山脊与近景。建筑、道路、路灯、地基和施工状态一致。浮层、坐标和计时文字更新只影响展示。

预览是独立小场景，显示真实形状与尺寸，分别处理主题、相机和摆放。导入身份和快照保留，尺寸限制见 ARCHITECTURE 与校验代码。

光照、天气和环境效果保留建筑与操作可见性，遵守减少动态和按需渲染。
