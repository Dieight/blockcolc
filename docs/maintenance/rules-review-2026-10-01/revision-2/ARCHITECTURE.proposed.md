# blockcolc 架构

这里说明模块职责与数据约束。产品行为见 [BLOCKCOLC](BLOCKCOLC.md)，测试和交付见 [TESTING](docs/TESTING.md)，当前进展见 [TODO](docs/TODO.md)。

## 模块

```text
apps/web
  页面、交互、展示、渲染器宿主
        |
packages/application
  用例、命令串行执行、显示数据、平台端口
        |
packages/domain
  命令、事件、校验、状态转换、业务数据
        |
packages/storage-indexeddb  packages/platform-capacitor  packages/voxel  packages/litematic
  保存、备份、CAS           原生生命周期与文件           世界渲染        本地 NBT 导入
```

`packages/domain` 管理保存的业务数据，不依赖 React、浏览器、Capacitor、IndexedDB 或 Three.js。应用端口由 `packages/application` 定义，适配器实现。

展示偏好、可恢复流程、业务数据和原生能力分别管理。页面与渲染器根据数据展示，通过现有命令修改业务状态；同一状态只有一个写入者。

标准和私有 Android 版本共用核心。标准构建排除私有传输与配置，私有构建接收明确指定的外部模块目录。私有传输留在公开仓库之外，上传失败不改变本地保存和计时。

## 状态与时间

`DomainState` 使用 schema `12`。只有已记录的旧数据迁移会转换旧字段；其他未知或格式错误字段被拒绝。主要数据包括：

- 活跃、暂停、纪念和软删除项目，稳定聚落索引，小任务和已完成的习惯建筑；
- 至多一个活动专注，以及只追加的专注历史和进度汇报；
- 专注完整性策略和中断协调所需的生命周期信息；
- 每日目标、日历、衰败策略、导入蓝图、装饰资源与奖励。

进度与状态采用整数基点 `0..10000`。时间戳使用 ISO 8601 UTC，已完成专注另保留本地完成日期。

Litematic 项目快照最多为 `96 x 96` 占地、`256` 高、`300,000` 个非空气方块。解析器另外限制文件、NBT 遍历和调色板；UI 显示当前 `64 MB` 文件上限。装饰资源上限为 `12 x 12 x 16`、`2,000` 个非空气方块。

专注按已保存的 `endsAt` 结束，不能暂停。达到结束时间时先完成，再处理迟到的后台或中断信号。完成和中断都保留实际耗时，中断不计完整轮次或施工进度。普通习惯专注完成后推进一轮，有限任务等待进度汇报或统一结算。

同一时间最多一个活动项目，ID 永不复用，每条完成专注最多归属一次汇报。进度只能增加，衰败只改状态。习惯任务没有小任务；完成建筑在源习惯删除后仍作为历史保留，不受衰败影响。活动会话或待汇报存在时，切换和创建项目仍受同一约束。

### 轮次计划

未完成安排保存在可恢复的本地 UI 上下文中；领域数据保存当前会话、阶段和 `endsAt`，领域备份不含 UI 计划。先保存计划，再采用新安排。进程重启保留上下文，明确取消或结算成功后清除。锁定计划的宿主决定展示和命令归属，当前所选项目变化不影响它。

极简使用延后结算的马拉松计划：保留宿主引用，`subtaskId` 为 null，schema `12` 的 `deferredSettlement` 标明结算方式。习惯延后计划等分配后再推进建筑。有限和习惯计划各保留原结算行为，迁移不为旧记录推断 `deferredSettlement`。

计划上下文丢失时仍可汇报已保存的完成轮次，剩余安排保持未知。

## 命令、保存与备份

`ApplicationService` 校验并串行执行命令，按当前仓库版本保存，成功后才公开状态与事件。`StateRepository` 使用 compare-and-swap，旧版本写入失败而不是覆盖新状态。

`IndexedDbStateRepository` 在 `appState` 保存校验后的聚合，`rollbackBackups` 保存不可变恢复快照，元数据另存。导入预览和校验后，在同一事务里备份并替换；恢复也先为当前状态建快照。大任务删除采用软删除并原子记录回滚信息。

备份封套版本 `1` 带规范化载荷和 SHA-256，载荷使用 schema `12`。解析前验证校验和，导入上限 `100 MiB`，按已记录迁移处理旧数据。自动回滚只留最新两份，用户导出文件不参与裁剪。

保存失败要显示失败，并保留可恢复草稿。跨存储步骤只有适配器提供事务时才具备原子性；后续 UI 上下文保存失败不撤销已提交专注。导入蓝图的身份与快照进入项目备份，恢复时不依赖新的内置目录。

## 页面与成就

- `App.tsx` 组合路由并管理应用服务生命周期；`command-runner.ts` 分发命令、刷新和显示普通反馈，保留异常。
- `ApplicationService.achievementsProjection()` 从现有专注、进度和建筑计算只读成就，不写事实或授予奖励。`unlocked` 和可空 `unlockedAt` 分开，未知历史日期保持未知。
- `StatsScreen` 仅在统计路由 `active` 时对照成就和本地展示 receipt。未展示项合成一次弹窗，关闭后写 receipt；写失败仍可关闭，提示以后可能重播。已有 receipt 的项不重播，加载、恢复和普通命令反馈沿各自流程处理。
- 计时流程管理平台交互，轮次存储管理计划恢复，世界宿主管展示。偏好和时钟使用现有写入路径，页面文字更新不重建世界。
- 极简汇报复用 `FocusReports` 的草稿、分配、重复提交保护和命令，只选择 minimal 展示分支。保存成功后退出，失败保留草稿。玻璃边缘取世界已完成帧的背景窄带，前景 DOM 保持原样；采样失败回退 CSS 玻璃，世界继续绘帧。

## Android 生命周期与通知

`AttentionStateMachine` 合并 activity、窗口焦点、多窗口和 OEM 小窗信号，产生一次前后台转换及对应的后台时长、电源、锁屏和系统 UI 快照。Android 的 `appStateChange` 不重复计离开；Web/PWA 的可见性检测是尽力而为。

共享协调逻辑依据保存的离开阈值、豁免和 `endsAt` 决定结果。App/bootstrap 在刷新前保存一次性提示；常驻世界显示短暂离开浮层，普通命令走全局消息通道。

通知从业务数据生成，不另计时间。专注和轮间休息共用互斥常驻表面，使用绝对结束时间；生命周期刷新保持身份，新计时器换身份，完成提醒有独立 ID。倒计时由 Android 绘制，WebView 不在后台逐秒运行或重发通知。

Android `16` promoted-ongoing 只在平台报告资格时请求。权限、AppOp 或 OEM 拒绝时保留标准通知并说明限制。设备锁屏、AOD 和 Fluid Cloud 的实际观察放在恢复矩阵或测试报告。

天气由 Web hook 在启用且世界可见时请求。Android 管定位权限、签名请求元数据、有界 HTTPS 解码和 app 私有 no-backup 坐标缓存。仍有授权时才复用缓存，关闭后清除；失败回退本地确定性天气，计时和备份保持独立。

## 世界与资源

- `WorldCanvasV7` 管常驻渲染器、HUD、建筑记忆和相机；`world-projection.ts` 适配只读应用快照，`voxel-runtime.ts` 在世界和预览间共享惰性初始化。
- `packages/voxel` 管地形、几何、图集、shader 和排序；`packages/litematic` 管有界 NBT 解析与规范化导入。业务进度仍由领域管理。
- 资源采用前先校验文件、解压条目、图像、图集和几何预算。范围见 [兼容说明](MINECRAFT-VISUAL-COMPATIBILITY.md)和 [26.3 调研](docs/research/MC-26.3-resource-pack-audit.md)。上游受保护资源不随应用分发；解析成功和原版外观等价分别验证。
- 图集页数与动画受 GPU 尺寸和配置预算限制。按整个方块解析，缺失或不安全的面、模型、图集页使整块回退。数值限制由代码和配置维护。
- 地形、道路、建筑、装饰和定向光共用可旋转根节点。按需请求帧，隐藏和后台停止。世界适配依据聚落，裁剪覆盖完整可见地形；海洋建筑、道路、支撑和路灯共用四格居住基准面。
- `scenery.ts` 从真实顶面、道路和任务/奖励保护区规划背景。结构走共用静态方块路由，主世界默认启用，小预览省略。树逐格合批，结构按投屏大小与迟滞选择细节，保留屋顶、街巷、船体和桅杆。背景可见性和阴影范围扩展，任务相机适配范围、旧地形、水系、布局和保存的身份保持原样。
- 降水在同一 `FrameRequestScheduler` 更新 GPU 时间 uniform，生成或覆盖变化时上传实例矩阵。可见且未减少动态时继续请求运动帧，拖动不停雨雪；隐藏和减少动态冻结时钟，恢复不追补。云沿低频自适应节奏更新。
- 日间太阳、夜间可见月亮产生主导直接光，夜间计入月相。材质明暗、阴影角度和诊断射线使用同一投影；无可见直接光时只留环境亮度。
- 阴影深度贴图和采样矩阵来自同一次绘制。普通光照更新不单改采样矩阵；时间/天文跳变、动效终点、可见性和上下文恢复申请刷新，其他帧合并。切档先准备新目标，失败留旧目标，成功再释放；复用画布重置 WebGL 交接状态，销毁释放自身阴影目标。
- 自适应画质分开统计稳定主帧与深度刷新帧预算。一次冷启动或切档绘制不等于稳定超限，持续交互耗时仍可降级。
- 旋转、双指/滚轮缩放、视口适配、`contentBounds` 和 `visibilityBounds` 分别管理。记忆面板开关保留聚焦，显式重置地图清除聚焦并恢复完整聚落目标。
- 画质只改变绘制开销。Cinematic/high 后处理可选且有界，balanced/low 的离屏目标缩为 `1 x 1`，自适应降级有最终决定权。隐藏、减少动态或能力不足时暂停相关动画，性能验证见 TESTING。
