# blockcolc 私有同步工作区

维护同应用私有上传模块、服务和查看页，不另建伴侣应用。主仓库由用户选择或 `-RepositoryRoot` 明确指定；任务范围、独立执行、成对出包及授权规则沿主仓库 AGENTS 和 `docs/TESTING.md`，协议见其同步工作包。

- 私有源码、凭据与服务配置不进入公开仓库；核对标准 APK 的实际隔离。私人包默认本地保留，当前授权允许时才安装或交付。
- 私有包与标准包共用冻结核心、版本、签名及非空 DeliveryRoundId，分别留 manifest 和摘要；不扫描邻居目录猜工作树，不并发覆盖公共核心或构建输出。
- 测试仓库先核对私有性，只传授权 APK 并回读摘要；部署不继承历史授权，先完成既有端到端/资源门禁并核对当前凭据有效性。
- 服务只持久化批准的日总量和必要技术元数据，实时快照在内存中有界保留；不记录任务/请求正文或密钥，使用合成测试数据。
- 上传失败不影响本地计时、保存和恢复；公开文档只记录非敏感边界，交付与部署证据留在私有工作区。
