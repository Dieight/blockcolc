## 产品气质与视觉语言

- 3D 世界是情感焦点；开始、继续或汇报专注是操作焦点。首屏同时展示已累积的建筑和下一步专注操作。
- 应用保持平静并以本地为先。进度和建筑状态是不同事实：风化可以改变状态，但不能抹去已汇报的任务进度。使用真实、不羞辱用户的措辞。
- 世界使用原创或已获授权的方块风格资产。可借鉴体素建筑游戏的氛围，但不得复制受保护的 Minecraft 品牌，也不得分发其纹理、模型、字体、音效、客户端 JAR 或 shader 包。
- 世界与应用 UI 使用不同的语义色板。每种状态除颜色外还须用文字和/或形状表达。世界 HUD 在明亮地形、夜景和天气下均保持高对比度。
- 支持浅色和深色应用主题。优先在所属样式表中使用语义 token，避免一次性颜色或仅限某个版本的覆盖规则。

## 字体、对比度与控件

- 界面文字使用系统无衬线字体栈，计时器使用等宽数字。像素风字体仅用于世界标签，且必须有可分发许可及系统字体回退。不要随视口宽度连续缩放字号。
- 保持稳定的字号层级：计时器约 `56px`（紧凑屏幕可用 `48px`）、屏幕标题 `22px`、分区标题 `16–17px`、正文 `15px`，元数据至少 `12px`。较长的任务标题可以换行至两行；计时器更新不能推动主要操作的位置。
- 普通文字满足 WCAG AA 对比度 `4.5:1`，大号文字满足 `3:1`。焦点指示器清晰可见且至少 `2px` 厚。玻璃表面上的小号统计标签使用专用的高对比度 token。
- 每个独立触控目标至少为 `44 x 44 CSS px`。紧凑视觉控件可以配更大的关联命中区，但命中区不能重叠。窄屏布局应换行或重排控件，不要缩小命中区。
- 支持系统字号放大至 `200%`、键盘导航、屏幕阅读器名称，以及中文输入法组合文本和文本中间编辑。相邻内容重渲染时，文字输入仍须保留可见的原生组合文本。
- 分别遵守 `prefers-reduced-motion` 和 `prefers-reduced-transparency`。动效不得妨碍下一步操作；减少透明度时应回退到可读的不透明表面。

## 导航与核心流程

- 四个主要入口为计时、任务、统计和设置。世界/计时是首个入口；首次使用从任务创建或习惯设置进入。
- 首次创建页按所选项目类型展示必填字段；单选和创建语义见 BLOCKCOLC。
- 每个状态只有一个视觉主要操作。次要操作保持弱化；沉浸/极简展示应保留明确且易发现的返回路径。
- 完成、中断和汇报使用不同视觉状态；共用组件不改变产品定义的模式归属、结算和建筑/进度区别。
- 任务编辑须在蓝图预览变化时保留可见输入。已汇报进度后，任务结构保持锁定，但仍可重命名和排序。删除或替换备份等破坏性操作应说明后果及恢复路径。
- 统计只表达可追溯事实，未知归属标为未分配。成就提示的时机由 BLOCKCOLC 规定，展示状态和 receipt 由 ARCHITECTURE 规定。

## 组件与材质

- 设置使用分组列表卡片：标题置于卡片外，包含语义分隔线、选中/禁用/错误状态，以及 Apple 风格的分段控件和开关。保留当前浅/深主题 token 和 `44px` 触控目标；不要套用归档的扁平行设计规则。
- 设置数字值共用右对齐列，单位置于描述末尾；默认无硬框，编辑时才出现柔和底色和可见焦点。普通字号保留 64px 列，大字号允许列宽和输入高度随字形增大，不截断合法数字；保留原暂存、IME、提交和取消语义。
- 材质按功能选择，不采用一刀切的玻璃规则：

  | 表面 | 材质契约 |
  | --- | --- |
  | 沉浸计时带 | 保留现有贴边矩形几何及本地 `0–100%` 玻璃偏好；偏好只改变材质，不改变尺寸或位置。 |
  | 世界 HUD、坐标、建筑记忆和临时状态 | 使用固定的高对比功能玻璃，不受计时器滑杆影响。 |
  | 设置分组卡片 | 使用固定的浅/深色玻璃，并限制边缘和阴影；减少透明度时回退为不透明表面。 |
  | 计划表单和任务选择菜单 | 在真实内容之上使用便于阅读的玻璃材质，并明确显示焦点与选中状态。 |
  | 正文、图表、输入框、破坏性操作和导航 | 使用稳定的语义表面；没有明确层级收益时不要增加玻璃材质。 |

- 计时带保留已接受的贴边延展矩形轮廓：手机竖屏时贴底，横屏/平板/桌面时贴右边。不要加硬边框或内嵌双线。文字和控件保留安全区内边距，同时允许世界背景延伸至透明系统表面下方。
- 玻璃折射仅从真实世界背景采样四条窄边带，以边缘曲率偏移，不复制/变形前景文字。中心透明且不接管手势；采样失败保留可读 CSS 玻璃，减少透明度时关闭采样。沿现有世界帧限频更新，不为玻璃另开持续动画。
- 每个受影响的材质都须检查浅/深主题与减少透明度路径。滑杆只控制沉浸计时材质；普通玻璃 token 不跟随滑杆变化。设置中默认仅显示通透度数值，点击该行才展开滑杆，避免滚动时误触；键盘同样可展开及收起。
- 施工清单编辑与大任务标题编辑共用右侧操作列。结构锁定说明放在清单标题下方，不挤占编辑按钮位置，不改变可改名、可排序及禁止增删的业务规则。
- 动效用于反馈或空间连续性。不要持续动画布局、弹跳计时数字、自动旋转世界或使用高频闪烁。雨雪属于天气投影，用户旋转世界时应继续落下，层次与可见性不能靠遮盖建筑取得；沿现有单一帧调度按需更新。页面隐藏、进入后台或启用减少动态时暂停，恢复不补跳；云等慢速环境效果仍按低频自适应节奏更新。

## 计时、极简模式与统计

- 沉浸表面在普通和极简模式间复用相同的计时槽、任务/轮次上下文槽和控件几何。极简模式不添加底部占位行，也不移动数字位置。专注进行中不得显示建筑完成百分比。
- 极简空闲模式沿用现有高面板，且只有两页内容可直接滑动切换：时钟和今日实际专注时间轴。不设置切页按钮或页码指示。左右滑动均须有效；键盘左右方向键提供等价路径。纵向选时与横向切页彼此隔离。
- 面板雨以方块轮廓、高光、轻重颗粒和滑落速度表达层次；雪以细像素雪点/雪花加远近速度和透明度分层，不用模糊光晕代替层次。底沿积雪按降雪强度非线性分薄、矮、中、高四档，短面板同比例压缩四档，不能压到中/高不可区分。前景文字和手势在惰性天气层之上，减少动态保留静态像素景，不改变已批准面板高度。
- 时间轴按小时分组，以 `15` 分钟方格表示实际专注区间。未占用时间保持空白；使用克制的绿灰色区分任务/习惯归属。同一小时内不编码先后顺序。图例和注释保留精确总量，并在玻璃表面上维持高对比度。
- 极简专注复用现有计划与计时流程。不要另造计时器、日程、任务或倒计时。正在运行的专注、待汇报状态和恢复错误优先于空闲时钟展示。
- 极简汇报直接融入同一贴边玻璃带，不再嵌入白底报告卡。实际时长为主层级，任务按细分隔线收纳，轮次与进度操作共享既有业务，说明默认折叠；底部主要提交可达，报告可触摸滚动。汇报可扩展其所需高度，不改变空闲两页面板已批准的高度。
- 图表使用应用语义色和易读的实底表面。无法从历史恢复的归属仍明确标为未分配；绝不平均或捏造数据。

## 世界、相机与蓝图预览

- 当前环境为自然山谷、经典空岛和海洋小岛。保留各自的轮廓及已接受的地形/建筑支撑行为；不要把某一环境的视觉几何套用于其他环境。
- 群系场景保留主任务建筑为主体。山谷和海岛仅各一处更远的背景村庄，不围成一圈；经典空岛不生成村庄。营地/残垣在有真实陆地支撑处落位，沉船靠岸并有水面以上可识别的船体与桅杆。树由真实方块构成，花按物种偏好成组；远景保留地标轮廓，不把一座结构糊成包围盒。
- 相机只支持旋转和有界缩放，不支持平移。内容适配依据聚落；裁剪仍覆盖完整可见地形，确保缩放极限处不会丢失远处山脊或近处山体。
- 保持主要建筑、地形支撑、道路、路灯和施工状态彼此一致。相机控件、浮层、坐标和计时文字只更新展示，不重建地形。渲染器按需请求帧，并可自适应调整画质，但不得改变已保存的产品事实。
- 蓝图预览是独立小场景，显示真实导入形状和尺寸；不照搬主世界相机或摆放假设。精确导入限制见 ARCHITECTURE 和校验代码，不在视觉规范重复维护。
- 导入蓝图保留稳定身份和已保存快照。视觉改进不得悄悄重排或改写已持久化的蓝图数组或用户导入内容。
- 天气、光照和环境效果不得遮挡文字、计时控件或建筑。遵守减少动态，并按需渲染。

受影响流程按 [`docs/TESTING.md`](docs/TESTING.md) 与专属 skill 的视觉清单验收，不固定跑遍无关状态。世界静态画面等待揭示结束后再判断，结合实际拖动/缩放；图片存在或非空帧不足以证明内容正确，浏览器证据不代签设备表现。
