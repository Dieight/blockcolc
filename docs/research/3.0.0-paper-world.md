# 纸雕世界的原生对照

纸雕 Demo 用 Canvas 2D。地面取规则高度网格，房屋和树用多边形表示。先旋转世界平面，再斜投影到屏幕并减去高度。多边形按远到近绘制，顶面和几组侧面着固定的色，做出裁纸叠起的厚度。

原生实验读取 V4 正式生成器产出的地形、道路、建筑及远近景物。纸雕端把顶面和侧面写成带色四边形，只提交方块外露的面。OpenGL ES 用正交相机变换顶点、用深度缓冲确定遮挡。地形和建筑共用一种颜色着色器，水最后叠一层透明色。旋转和缩放更新相机，几何留在显存缓冲中；场景不动时按需出一帧。

这轮保留了真实的地形形状和建筑方块位置。复杂方块形状近似为体素外壳，玻璃用色块代替，水面保留珊瑚的可见性。动态天气、阴影、倒影、动物、室内和命中交互仍需要单独评估。

## 测量口径

对照是原生世界的「流畅」档、原创材质、晴天 15:00。每次用同一份含 25 栋建筑的合成存档重新生成空岛或万象海岸。空岛有 6 个景物。完整海岸保留远近地形，共有 440 个景物，其中包括珊瑚。每个聚落的布局、地形和景物摘要均核对一致。

环境为 Android 15 模拟器，使用宿主 RTX 3070 Laptop GPU。两端使用 720 × 960 输出、同一相机中心和拖动输入。纸雕用正交投影，按输出尺寸绘制。流畅沿用透视相机和档位自带的内部分辨率，本次为 411 × 549。两端均从完整地形重新生成，正式 App 的持久化衍生缓存未参与。

App 进程的 CPU 使用量按一颗逻辑核折算。PSS 是场景稳定后整个测试进程的比例常驻内存，包含公共生成数据及测试宿主。测试每秒发 30 个拖动事件，持续 5 秒。帧间隔取 SurfaceFlinger 的呈现记录，P95 越低，说明这一段拖动中较慢的帧间隔越短。静止时纸雕按需绘制，原档继续驱动动态世界。模拟器结果用于同环境对照，真机 GPU 占用、功耗和帧率上限需另测。

## 结果

每个聚落和渲染端各测三轮，取中位数。下表从流畅档读到纸雕。首帧计时起点为共享地形就绪，包含组装渲染数据、上传和第一帧渲染。海岸末轮超过了首次 Perfetto 录制时限，所以帧间隔单独补采一轮。

| 聚落 | 地形就绪到首帧 | 稳定 PSS | 旋转 CPU | 旋转帧间隔 P95 |
| --- | ---: | ---: | ---: | ---: |
| 空岛 | 16.96 秒 → 1.67 秒 | 287.9 → 182.2 MiB | 181.7% → 12.3% | 119.1 → 37.4 ms |
| 万象海岸 | 45.96 秒 → 3.74 秒 | 495.5 → 266.0 MiB | 191.9% → 12.4% | 152.1 → 36.9 ms |

持续拖动时，纸雕三组有效采样中每组都没有达到 100 ms 的帧间隔。流畅每组空岛有 8–10 次，万象海岸有 21–22 次。纸雕上传的顶点与索引约占空岛 9 MiB、海岸 36.5 MiB，实际显存还包含其他缓冲和驱动分配。

共享地形和景物在纸雕组仍分别用时约 24 秒和 41 秒，因此全量生成时这一步占据了绝大多数时间。完整实验的空岛耗时从 37.6 秒到 25.6 秒，海岸从 88.8 秒到 45.3 秒。这是模拟器从零生成的计时，正式 App 冷启动还涉及缓存、存储与页面调度，需要单独测量。

## 复查

首轮 OpenGL ES 原型通过 [`androidTest`](../../apps/native-android/app/src/androidTest/kotlin/com/blockcolc/preview/P4PaperWorldRenderTest.kt) 运行。使用已核对的诊断构筑对和 `blockcolc_p3_api35` 模拟器，通过 `artifacts/experiments/v3.0.0/p4-paper-world-r63/measure.py` 运行。传 `--repeats 3` 跑两组聚落，传 `--world mosaic-coast` 可单独采海岸。该目录的 `comparison.png`、`host/results.json`、`host-coast-frames/results.json` 分别保存画面对照、主实验和补采数据。两轮均核对恢复了模拟器原 APK。

## 接入原生预览

App 沿用 Filament 的相机、天气更新和同帧玻璃合成。选中纸雕后，生成线程从布局、原始方块和地形直接组装纸雕网格。每个顶点存坐标和四色通道，使用无光照的色块材质。地形、道路和景物使用独立的派生文件缓存，建筑和奖励按归属更新。天气、镜头和色彩滑杆更新渲染参数。

云由低速移动的薄色片叠成。雨使用两片交叉的短斜条，雪使用薄方粒，降水实例数受统一上限控制。日夜、雾距和雷雨色调复用当前天气和镜头，雷雨沿用现有闪电时间线。陆地动物、鱼和鸟沿用活动与碰撞规则，画成少量面色不同的方块，远处减少细件，出了视野停止绘制。

模拟器经设置进入纸雕，核对普通与极简往返共享同一渲染世界、玻璃取用同一帧。纸雕镜头沿视线拉开深度范围后，极简近景的地形切口消失。另测试重新打开工作区命中纸雕静态包，提交施工只替换变化的建筑。世界色彩仍可调整亮度、对比度和饱和度；兼容现有云端时同步档位按流畅传输，设备本地保存纸雕。 [普通模式画面](../../artifacts/experiments/v3.0.0/p4-paper-world-r63/paper-modes-r68/p3-pages-paper-modes-r68-timer-modes-paper-ordinary-3a04b9eb-03b8-46f0-ad49-d8f6baaf43a0.png) · [极简模式画面](../../artifacts/experiments/v3.0.0/p4-paper-world-r63/paper-modes-r68/p3-pages-paper-modes-r68-timer-modes-paper-minimal-bd33a345-29f2-4a95-9bf0-db63c29bbb58.png)

### OnePlus 实机对照

用接入 App 的 Filament 实现和原流畅档各跑一次。两档使用同一诊断构筑、每种聚落相同的 25 栋建筑和布局、720 × 960 输出和 5 秒 150 个固定拖动事件。PSS 取稳定画面下整个测试进程，旋转 CPU 按一颗逻辑核折算。以下顺序为流畅档到纸雕档。

| 聚落 | 稳态 PSS | 旋转 CPU | 实际呈现间隔 P95 |
| --- | ---: | ---: | ---: |
| 空岛 | 406.5 → 304.3 MiB | 115.3% → 76.2% | 49.95 → 49.95 ms |
| 万象海岸 | 575.6 → 442.5 MiB | 131.0% → 113.9% | 41.63 → 41.62 ms |

四轮都没有达到 100 ms 的帧间隔。纸雕的稳态 PSS 低约 23–25%，这组输入下两档的 P95 基本相同。每组一次、使用固定输入的实验宿主；功耗、长时旋转和真实启动各自另测。已核对测试前的预览 APK 和 test APK 恢复。 [真机回执](../../artifacts/experiments/v3.0.0/p4-paper-world-r63/oneplus-paper-r66/result.json)
