# 世界动物正式接入

2026-10-17～18。状态：实施、最终定点及成对构建完成，私人测试包本地待体验。

用户审看[方块羊演示](2.8.0-world-animals-experiment.md)后批准把剩余动物接入正式 App，补充停走平衡、变化的速度和非直线路径；本轮只做定点与私人测试包，不运行全量，不操作手机或上传。

## 采用的范围

山谷与海岸的羊、牛、猪、马；山谷河鱼，海岛／海岸的银色海鱼与彩鱼；全部环境的海鸥、燕形鸟和林鸟。陆地走动、吃草／休息交替，鱼群转向和偶发鱼跃，鸟起落、曲线飞行与停栖，均有轻点的小回应。使用原创长方体、关节和像素贴图，没有封装 MC 实体素材，也不宣称复刻完整 MC AI。

正式模块归属见 [ARCHITECTURE](../../ARCHITECTURE.md#世界与资源)，当前行为见 [BLOCKCOLC](../../BLOCKCOLC.md#世界与资源)。原[讨论稿](2.8.0-world-animals-proposal.md)保留当时取舍；其中“尚未接入”只描述实验阶段，不代替本记录。

## 与原型的差别

- 不复制／索引整个地形为另一套碰撞对象；实际地表表共用空间索引，移动查询不保留小数点历史。结构只先索引原方块的列位置，查询时采用共用形状，最多缓存 8192 个碰撞长方体。结构索引和动物出生分段放在有效世界首帧之后，不拖住开场；换场只暂存旧姿态，不把旧 Walker 及整张导航图留到新场景后面。
- 出生地倾向近景，但游荡目标相对当前位置，不以家园半径或建筑区包围盒禁行。多层地面、净空、步高、跳落和延迟帧检查从已验原型迁入；在线搜索仍有预算并可取消。
- 对角路线、有限的弧度与渐变朝向都经过实际通路检查；速度由物种、个体、时间与活动状态共同变化，吃草与停留错开，不让全群一直匀速奔跑。
- 动物共用四个实例批次（部分可为空），活动时按约 30Hz 更新，全部停留时降低姿态更新频率；视野外休眠，不每帧重绘整张太阳阴影图。脚下用接触阴影，世界本身的缓存、建筑身份和材质路由独立。着色器的实例颜色特征在初次准备前建好，避免动物出现时才切换 shader 变体。
- 原型看不到水下鱼的问题在正式水面处理，不能把鱼强行画在不透明水上。小预览和诊断平涂不包含活动层，原独立羊 Demo 显式关掉正式动物，避免双层重复。

## 验证进展

原始记录在 `artifacts/verification/v2.8.0/animals-production-20261017/`。

- 首轮类型检查发现生成器取消参数、模型尺寸参数与测试方块类型问题，后续均修正；可运行首轮纯测试 32 通过、2 失败：鱼跃补独立冷却，鸟的合成目标改到试件边界内。惰性索引与新增预算测试的两次类型错误也保留工具输出，没有跳过类型检查。
- 首轮浏览器三环境通过，随后点击检查超时。核对后是测试错误地假定“聚焦第一栋建筑就一定有可见动物”；未对准或被遮挡的投影点不能作为实际点击坐标。返修为对准真实动物，用独立射线确认可见性，再经真实鼠标事件检查回应、矩阵和画面像素。出生位置同时改为室外，鱼按小群出生、鸟不与陆地动物挤在同一位置；出生偏好不变成活动禁区。
- [unit-final2.json](../../artifacts/verification/v2.8.0/animals-production-20261017/unit-final2.json) 的 44 项纯测试通过；两模块类型检查通过。[browser-final2.json](../../artifacts/verification/v2.8.0/animals-production-20261017/browser-final2.json) 八项通过，包含三环境、空岛、点击／拖动、真实水下鱼与夜间反射，以及原创／导入材质的网格保留；无跳过或重试。
- 审图发现海岛透明水面会叠出深色矩形；单改深度策略后八项虽通过，远景仍有叠色，因此又采用近处透明、远处恢复不透明的响应，海岸保留透明珊瑚的原排序。已审看最后远景，矩形消失，水下鱼及夜间反射保留。结构改变时还清理旧飞行／鱼跃轨迹，并修正原型按子串把草方块、开花树叶和南瓜灯当成软植物的分类。
- 最终冻结的 [unit-delivery.json](../../artifacts/verification/v2.8.0/animals-production-20261017/unit-delivery.json) **47 项通过**；[browser-delivery.json](../../artifacts/verification/v2.8.0/animals-production-20261017/browser-delivery.json) **八项通过**（4.5 分钟，退出 0，无跳过或重试），Web／voxel 类型检查通过。上述早期结果只保留为迭代证据，不与最终结果累加。资产检查通过，发布分类检查只枚举 371 项、没有执行全量。

构建与两个包的最终身份见 [/98 工作包](../versions/V98.md)，[配对证据](../../artifacts/verification/v2.8.0/animals-production-20261017/paired-test-evidence.json) 已核对 34 个共享核心资产、签名、通道隔离、无探针及摘要。本轮没有手机安装、远端上传或发布；动物增加的持续绘制不能凭实例批次或桌面 CPU 时间推断手机耗电。

手机功耗、原生触控手感和用户对数量／步态的体验未测。自绘实体不沿用资源包的实体模型；任意自定义方块碰撞仍为共用原创形状或保守长方体，不承诺完整导入模型物理兼容。
