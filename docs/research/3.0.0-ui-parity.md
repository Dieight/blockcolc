# P3 界面对照与返修

构建 4 没有通过体验验收。本轮以原版实际界面为准修复迁移差异，不把“数据正确”“可以操作”视为视觉通过。

## 对照依据

- 公开 v2.8.0 /99：提交 `c9be3f8a46ec4fadfcb6e560ecaca583b3b9858e`。源码独立归档，并通过自己的生产构建采集截图、DOM 字体和位置。
- 工作区未发布的 v2.9.0 /104 与 OnePlus 原版：保留后续已修正的业务和交互。极简入口与模式动画直接对照当前 `WorldScreenV7`、`mode-transition.ts`；新增的 `formal104-notes-reference` 是本轮实际运行 /104 源码取得的普通便签、极简便签与计时画面。手机上的正式 App 只读查看，不开始、结算或更改真实计划。
- 构建 4 的 1,340 份源输入按交付摘要核对后留档，避免把返修后的源码当作被用户拒绝的旧候选。

文件都在 `artifacts/experiments/v3.0.0/p3-ui-parity-20261031`；状态截图使用合成数据和原版领域命令，未复制用户任务进入浏览器。`formal99-complete-reference-2` 覆盖普通／极简／马拉松、专注／休息／等候／汇报、建筑记忆、任务创建、纪念建筑、浅深主题与系统字体等状态；`formal99-secondary-reference-2` 补齐习惯任务、每日目标、成就和三档玻璃。早期采集有选择器错误和未等动画完成的截图，失败保留；调整页以 `formal99-adjustment-reference-3` 为准，加载画面以显式定位原 CSS 动画时刻的 `formal99-loading-reference-3` 为准。

## 保留的已确认改动

独立页头移除；设置搜索、重新细分的设置分组、像素开关、混合字体；室内外切换、室内成就奖励与摆设；当前计时和存储规则。这些不因采用原版视觉而删除。

原版 Web 独有的天气角标不带入 Android。不得为追求静态截图相似，改变真实任务名称、历史时长、轮次归属或保存结果。

## 已查明的原因

- 展开：动画容器没有在展开途中裁切子内容，另有无条件内边距让空列表增高。
- 玻璃：原实现每 250ms 复制一张最多 384px 的世界图；旋转时自然与世界不同步。改成世界渲染内的同帧后处理。实机另发现布局坐标仅在副作用中读取，没有让组合订阅布局变化，初始零矩形因而没有重新提交；现显式观察布局，并使用物理四角计算，最后由世界边界裁切。
- 室内：旧构造未使用完整建筑方块路径。相机另用一格朝向向量计算雾距，遮住了窗外建筑；应分别使用朝向和观察聚落的实际距离。提交回执也早于画面呈现，已增加呈现栅栏。
- 滑杆：轨迹的原始落点和按步长对齐的数值混用，落地后又短暂显示落盘前旧值；现在分开飞行、对齐与保存回执。
- 固定弹页：Material 3 的全屏弹页主题设成了非浮动窗口，系统即使报告支持模糊，也不会按预期绘制窗口背景模糊。修正预览工程的弹页主题，并沿用原版固定玻璃的两层有效透明度；不读取残留极简截图。条件依据见 [Android Window API](https://developer.android.com/reference/android/view/Window#setBackgroundBlurRadius(int)) 和 [AOSP 窗口模糊说明](https://source.android.com/docs/core/display/window-blurs)。实际效果须审看手机画面。

蓝图等含独立世界预览的弹页不使用窗口模糊，避免过滤预览本身。其余固定功能弹页的 OnePlus 返验已看到真实窗口模糊，背景文字不再清晰透出。这里仍有一处平台差异：背景模糊覆盖整个弹页 Window，弹页上方露出的聚落也会柔化；原版 CSS 只模糊面板覆盖的区域。它不使用旧世界截图，也不改变主计时玻璃的通透度曲线。该差异应交给用户体验判断，不能写成逐像素完全一致。

## 还原时采用的度量

| 位置 | 原版实际值／结构 |
| --- | --- |
| 普通计时 | 移除页头后世界占可用高度 45%（本轮用户允许的调整）；48px 时钟；21px 项目与当前小任务；12px 元信息；52px 开始按钮 |
| 极简与专注 | 266px 信息区、64px 时钟，上下各有固定的上下文与操作位置 |
| 调整中的任务 | 大任务 16px、小任务 14px、说明 12px；子项左缩进 28px；透明底加左侧选中条与勾号 |
| 任务 | 今日目标 200px；项目标题 17px；施工行 15px／说明 12px；16 段施工进度 |
| 统计 | 时长数字 28px／单位 15px；26 周热力图；100 点团簇，最多六项明细，其余合并 |
| 建筑记忆 | 替换原工作台，两列投入信息与底部继续入口；奖励使用世界下缘短牌 |
| 设置 | 60px 行高，标题 16px、说明 12px；不因保存偏好而临时禁用整页 |

这是迁移对照记录。系统字体、字体缩放和安全区仍由原生布局处理，不把一个设备的物理像素写成其他设备的固定偏移。

上述代码修复仍需对应的实机画面和操作记录。局部通过、截图、失败与恢复摘要记在版本日志；这里不替用户作最终验收，也不提前进入 P4。
