# v2.8.0 不同地形之间的过渡

实验：2026-10-16；整理：2026-10-17。状态：隔离原型完成，尚未采用。接续[世界外观审计](2.8.0-world-appearance.md)，回应用户追加的「不同种地形之间的过渡和融合」。

后续：用户已批准采用有效方向，正式取舍与验证见[外观整合](2.8.0-appearance-integration.md)；下文保留本轮实验原始结论。

## 先说结论

现在的问题不只是两块地表的颜色不同。高度、表层方块、树种和近岸海床各自决定交界，位置不完全一致；把颜色抹匀或在群系之间塞一条草地，都解决不了它。建议保留九区构图，把山势、气候身份、地表规则和景观适宜度分开，再让它们共享同一套空间字段。

这轮没有直接更换生成器。两组原型在真实渲染器中完成对照，裸岩交界和近岸联动有参考价值，但整体高差没有明显改善；仍需继续打磨，不应以测试通过为由直接进入正式世界。

## 当前实现的交界在哪里

| 层次 | 审计结果 | 影响 |
| --- | --- | --- |
| 构图 | `mosaic-terrain.ts` 以旋转坐标及少量扭曲组织九区，尺度随 `coreRadius` 改变 | 这是既定构图，不是要去掉的错误。扩建后背景仍可能重排，单独留待生成规则讨论 |
| 高度 | 基础丘陵上叠加雪山、冰原、台地和林地各自的增高量 | 两区重叠不等于共享山体，可能形成额外隆起；只柔化材质不会改变它 |
| 表层 | 西侧按冷／热权重择类，其他位置仍有阈值、固定雪线和特例 | 垂直或俯视时能看出清楚的换材线。此前取消冰原／恶地间的建筑草带是正确约束，不能重新引回 |
| 海岸 | 多个海域用并集控制水域，低沙岸另作处理；海床又独立取噪声 | 水域与海底深浅未完全协调。但旧的斜沙条已修，实验必须保持现有水域轮廓，不能为做缓坡又破坏海域并集 |
| 植被 | 景观会读最终地表，但部分树种还受区域或单个 biome 标签限制 | 只有高度连续，树种和密度仍可能突然变化。23 区低处的过渡林与 33 区高林地不是同一个高度包络 |
| LOD | 不同分辨率的邻格采样与立面接合 | 属于上一轮的层级边界问题，不是群系交界本身；两种实验没有混在一起 |

正常世界走 `planWorldScenery`；旧装饰导出不是本轮正常画面的叠加来源。任务／每日奖励的保护与真实支撑已有实现，本轮不撤掉这些约束。

## 查到的资料

只使用官方或作者资料，并区分适用范围。

- [Mojang 的 Java 世界生成实验说明](https://www.minecraft.net/en-us/article/new-world-generation-java-available-testing)：山体形状与海拔不再完全由群系决定，群系碰撞和微小斑块也需要独立处理。说明还提到按气候／高度匹配山地、裸岩等过渡。这是 1.18 的设计背景，不是 Java 26.3 的精确算法。
- [Microsoft 世界生成概览](https://learn.microsoft.com/en-us/minecraft/creator/documents/world-generation?view=minecraft-bedrock-stable)：地形、气候／群系、地表、结构和特征有不同职责。它讲的是 Bedrock，这里只借用分层思路。
- [Red Blob Games：用噪声生成地图](https://www.redblobgames.com/maps/terrain-from-noise/)：高程之外再用水分等字段决定地表，避免所有类型都排成按高度分层的色带。我们的九区构图仍是额外约束，不能把该示例直接当最终世界生成器。
- [Mojang 1.18 预发布说明](https://www.minecraft.net/en-us/article/minecraft-1-18-pre-release-1)中的新旧地形 blending，主要处理已生成旧区块与新生成区块的接合。它不等于本轮的群系过渡，也不等于远近景 LOD 补缝；不能因为名字相同就搬来解释材质融合。
- 本机用户提供的 `26.3.jar` 确认为 `26.3`。普通主世界使用 noise generator／multi-noise biome source；`overworld` 数据包含大陆、侵蚀、脊线、温度／植被等路由，`offset`／`factor` 有样条结构。表层入口在该 JAR 中叫 `material_rule`，不能沿用旧文档的字段名猜测。暖海珊瑚特征还经密度、散布、高程和群系条件放置。这里只核对数据结构与引用，不反编译、复制生成实现或分发素材；[条目摘要与散列](../../artifacts/visuals/v2.8.0-biome-transitions-20261016/reference.json)保留。

由这些资料推导出的项目方案是：用连续山势承载离散方块，用相关空间字段决定不规则交界；不是把雪、草、沙和陶土的 RGB 混成中间色。冷／热紧邻是九区构图的艺术取舍，不可能靠一个插值公式变成真实气候带。

## 两组隔离原型

三组共同使用现行渲染器、精细远景、晴天 15:00、balanced 与同档立面暗色 `0.65`，没有混入上一轮表土／纹理／近中景候选。不读取正式数据库，不修改生产 voxel 文件、存档、种子或缓存格式。

### A：只改地表交界

高度、水域、低沙岸完全沿用现状。把雪线和交界放到相关噪声中，在冰原／恶地之间试不规则裸岩带，而不是建筑草地；独立保留 23 区的过渡林适宜度。候选仍输出具体方块种类，不做颜色糊合。

它适合作为负对照：如果山势依旧生硬，原因不能归给材质。缺点是标签变化仍会影响现有树种筛选，景观密度还没有改成完整的连续过渡。

### B：山势与海岸联动

在 A 上增加两项：

1. 用较平滑的共享包络组合山势，减小多个增高量叠加的隆起，台地只在恶地主导时保留明显阶地；向低沙岸更早收坡。这里用的是项目自写的 p-norm 原型，不声称复刻 MC 密度场。
2. 海床使用同一水域判定计算近岸距离，向岸边变浅；水面不动，珊瑚读取同一海床，浅水不放可能越出水面的礁体。

距离近似是 8 格网格、16 个方向、48 格内的有界搜索，插值后使用；不是精确距离变换、侵蚀模拟或水流求解。只在实验内保留一个 seed／半径的有界缓存，尚未比较手机代价，不作为新的生产缓存方案。

## 实验中的反例

首稿虽然通过初始锚点和水域检查，审图仍发现 23 区的小片杨树林减少。原因是把「林地高度包络」误当成「所有林地的身份」，漏掉低处过渡林的构图条件。先补反例，确认失败为 `valley` 而非 `forest`，再分开高度与适宜度，修复后原断言通过。[失败日志](../../artifacts/visuals/v2.8.0-biome-transitions-20261016/forest-regression-first.log)保留，未放宽预期。

首稿还用局部水平集值除以斜率估计海岸距离，在坡度很小处产生突兀的水下深浅带。最终换为上述有界搜索，实际截图中的该带减轻；原截图和 `candidate-ecotone.ts` 保留，不能以最终图覆盖首稿问题。礁床形状仍偏规则、山脚仍有层层刻线，这两项没有因换距离算法就解决。

## 最终结果

固定 3 个半径（26／66／120）、3 个种子和 3 条路径，共 27 行原始采样；实际渲染另用默认种子的 24／60 栋与另一种子的 24 栋，各三路径、两个视角，共 18 张截图。

下面只列默认种子、半径 66、每 4 世界单位采样的结果。统计不含最终建筑保护与 LOD；两侧群系标签变化后，所谓「群系边」集合也会改变，不能把它当同一边界的质量评分。

| 指标 | 现状 | A 只改地表 | B 山势／海岸联动 |
| --- | ---: | ---: | ---: |
| 22801 个点的水域变化 | 0 | 0 | 0 |
| 高度变化点 | 0 | 0 | 1924 |
| 材质变化点 | 0 | 422 | 428 |
| 全部陆地邻点高差 P95／最大 | 4／13 | 4／13 | 4／13 |
| 群系交界邻点高差 P95／最大 | 2／7 | 2／7 | 2／6 |

因此这轮不能宣称「整体地形变平顺很多」。A 的价值在表层交界，B 在部分山脚与海岸衔接；单个最大值变小不是全局质量提升。

实际世界中，24 栋的地形三角形为 `93136 → 93246 → 93456`，60 栋为 `95932 → 96014 → 95720`；没有出现上一轮表土几何的大幅增面，但这不是 GPU 帧率或启动耗时测量。三组任务位置、每栋 9 点地基高度／材质与实际水面几何都相同。B 的近岸海床最高从约 `−5.16` 变为 `−1.10`；24 栋默认种子的礁体对象从 28 减到 23，最高体素顶面为 `−1.5`，低于水面 `−0.34`。数量减少来自浅水放置限制，不是遗漏后当优化记录。

已实际审看默认 24 栋三路径、60 栋、另一种子与旋转角度：过渡林恢复，裸岩带可辨，海岸水下的异常带减轻。仍有清楚的大片群系分区、礁缘和山坡刻线；不能说已达到完整 MC 世界生成观感。

## 接下来怎么收敛

1. 先采用同一套字段的职责划分，再分别审雪岩线、冰原／恶地裸岩带与林缘密度；不要把所有变化一次塞进新生成器。树木候选要读同一适宜度，但坡度、水域和保护区仍有最终否决权。
2. 海床与礁缘独立打磨：从统一近岸距离出发试沙道、等深线与较破碎的礁缘，而不是继续增加珊瑚总数。当前 B 仅能作为方向，不整组采用。
3. 山势更换留在隔离实验，扩大种子与极端扩建对照。旧世界是否保留背景地貌、什么时候重建以及缓存身份如何变化，在采用时另定；现在不动用户世界。
4. 与上一轮 LOD、高频纹理和表土外观分开推进；它们看起来都像「边界」，但不能用同一个平滑开关处理。
