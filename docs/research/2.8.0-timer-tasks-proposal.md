# v2.8.0 计时与任务页提案

2026-10-14，待用户讨论；未实施。当前 App 与 Web 均已恢复 v2.7.0 的布局。已按后续讨论制作[计时、任务、设置与转场 Demo](2.8.0-ui-motion-demo.md)，不替换生产页面。

后续审看结果：计时排版不采用；任务主界面、设置整合和世界展开转场获准落地。新增任务与每日目标弹页不变。实施结果在 [开发记录](../versions/2.8.0-development.md)，以下保留原提案。

## 方向：让界面像世界下方的操作台

计时不再做信息仪表盘。保持世界画幅与沉浸模式，把下方分成三层：一行任务上下文、居中的时间、一个开始动作。任务名与小任务名有明显主次，轮次和调整收在同一行，不重复放两个指向相同页面的控件。极简入口仍在世界下方右侧；本次 Demo 将传送门改为世界展开／收回，正式版本仍保留原转场，等用户审看后再决定是否替换。

视觉上沿用像素图标和主题色，但只在时间刻度、进度与按钮边缘用像素细节；不为每个数字加框，不把整个页面切成多张同样的卡。普通页保持稳定实底，进入专注后才让玻璃成为主角。

任务页仍是「今天要做什么」在上、「管理任务」在下。今日目标是一条紧凑进度带，便签紧接其后；当前大任务作为一张展开的施工清单，其余任务收起。改名、排序与删除留在管理状态，不在每一行堆按钮。完成项保留在折叠区，不与下一步争视觉权重。

## 先确认的两件事

1. 普通计时页继续保留当前世界高度，不为新 UI 改相机或缩放；先只调下方的排版、字级和留白。
2. 任务页保留今日目标优先，而不是 /85 将管理操作放在最前。新样式先拿真实页面状态做小范围比较，再决定是否采用。

讨论通过后再做正式画面的方案；本轮不替换现有 UI，也不因提案修改业务流程。
