## 它如何运动

- [`motion.mjs`](C:/Codex/arbor/public/motion.mjs) 按稳定节点 ID 留住位置、生长量和速度；目标反向时从当前姿态继续，不重新从起点播放。
- 展开时父层先长、子层最多延迟 140ms；收起时深层先退。欠阻尼弹簧按经过时间推进，不依赖帧数，减少动态时直接落在终态。
- [`renderer.mjs`](C:/Codex/arbor/public/renderer.mjs) 将节点生长量投影到父枝上的位置，Canvas 逐帧绘制整棵空间树。不是单纯替换 CSS 缓动即可取得同样效果。
- 原项目的 [motion 测试](C:/Codex/arbor/tests/motion.test.mjs) 包含反向、整棵子树收回、不同刷新率与减少动态的约定；这里只审代码，没有重跑其测试或宣称手机收益。

## 哪些合适

任务层级、蓝图库分组适合借鉴稳定身份、反向接续和父子层次；未来做任务关系图时，枝条生长的隐喻也有用。当前长任务列表已有保留 DOM 身份与测量端点的开合：`ui/AnimatedDetails.tsx` / `ui/Reveal.tsx` 反向时读取实际中间高度，避免从头弹出。

这轮不引入整套树枝效果：普通设置是阅读列表，不是空间树；逐项弹簧、延迟和布局变动会延长信息出现，也容易重新引入用户指出的展开卡顿。现有开合保持紧凑，不额外添加粒子、全量 Canvas 或逐帧重排。上述可借鉴原则保留作后续交互设计依据，而非新增一个动画框架。
