## 范围

以 v3.0.0（c9caada）原生 Compose 源码为基准审查各页，用户确认采纳全部建议，以下两项除外：

- 极简时钟不在画面上加“上下滑动设定结束时间”提示，改为在新手教程“极简与便签”一步说明滑动。

## 实现取舍

- `PixelCopy` 留在单次转场留帧。合入审查撤回了周期画面取色和全局文字光晕，避免进入世界的常驻渲染路径。
- **页码不可点。** 审查 Demo 中页码可以点按跳页；落地时发现面板底部是既有的双击显现区域（测试在面板 94% 高度双击），因此页码只显示位置。
- **生日开关。** 已有日期时打开开关立即保存；从未设置时打开日期弹页，取消则保持关闭。
