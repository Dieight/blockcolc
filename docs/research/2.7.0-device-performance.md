## 进入后的表现

- 每次开场完成后独立观察 10 秒：两版共八个窗口均无长任务，rAF P95 约 16.7–16.8ms。旧版这批也未复现进入后的一秒停顿，不能声称由此次改动消除了该故障。
- 真实 ADB 首次旋转：最大 rAF 间隔 474.6 → 283.1ms、最大长任务 471 → 277ms；仍存在明显首次尖峰。首转两版都触发已有动态降档（low / DPR 1.25），不能把之后的交互当作精致档成绩。
- 再次旋转：最大 rAF 间隔 50.0 → 41.6ms，两版均无长任务；P95 同为约 16.7ms。新版 renderer CPU P95 12.3ms，旧版 9.6ms，不宣称稳定旋转全面更快。
- 有界缩放处理：最大 rAF 间隔 33.4 → 16.8ms，两版均无长任务。这是通过真实 renderer 处理器派发 WheelEvent，不是硬件双指捏合。
- 热返回：最大 rAF 间隔 116.7 → 133.4ms、最大长任务 123 → 136ms，没有明显收益。两版返回后世界重建计数仍为 1。
- 实机保持原极简偏好，导航按钮隐藏，任务/统计/设置切页按脚本跳过；没有为获得成绩改用户设置。它们仅有本版浏览器定点证据。
- 所有正式样本错误计数为 0。设备未提供 GPU timer，rAF 只是呈现机会，renderer CPU 包含驱动提交和等待；不把这些数值写成 GPU FPS。
