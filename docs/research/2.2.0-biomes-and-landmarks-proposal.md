# v2.2.0 群系、地貌与聚落场景提案

2026-10-01，用户已采用原型并授权本版完整实施：山谷、海岛村庄再推远，空岛不生成村庄，其余地点体量/位置由 root 决定。正式生成已接入；原型与新主世界证据分开保存。root 独立研究和实施，不委派。

## 方向

“装饰”扩大为环境本身：地貌确定场景骨架，群系决定植被与地表，村落/遗迹形成可辨识的地点。花、草、树只是其中一层。
不在现有世界上继续均匀撒模型，也不把每一种 MC 结构都塞进一个小聚落。

| 现有环境 | 地貌与群系骨架 | 可选地点 / 结构 | 植被与地表 |
|---|---|---|---|
| 自然山谷 | 山脊—开阔草甸—河谷，外围可见的浅峡谷/岩壁 | 旧木桥、废弃营地、小片遗址；森林边缘可选小村落 | 真正的方块树群、林缘混合花丛、树下落叶与倒木、湿地芦苇 |
| 经典空岛 | 保留悬浮岛及既有高度/水系，不生搬大陆深峡谷 | 不生成村庄；少量小型苔石/残迹，保留任务建筑空间 | 草甸/疏林斑块、疏树和混合花丛，留出建筑轮廓 |
| 海洋小岛 | 主岛—沙滩—岩岸—浅水—卫星岛的连续带 | 小码头/渔业营地、搁浅或半露水面的沉船、小岛旧灯塔/残垣 | 小片海岸树林、沙岸草丛、浅水珊瑚；不让陆地花园出现在海面 |

每个 seed 选择一两个主要地点，其他地方保留空白；不保证每一张地图同时出现全部候选。上表是可讨论的内容库，不是本版全部实现清单。

## 生成顺序与边界

1. 保留任务建筑、道路、地基和已有奖励的位置；先划保护区。遗迹/村落不会记入任务、统计或建筑记忆，也不触发任务建筑点击。
2. 用稳定坐标噪声划出群系斑块，结合坡度、高度和水位；外围地貌先规划，地点再按地表支撑和占地放置。
3. 树由真实单格树干、枝条和多层叶块组成；花是有中心、密度梯度和局部物种偏好的混合花丛。普通/原创材质与用户导入包共用方块路由。
4. 最后填落叶、草、石、芦苇等小尺度细节。结构与植被共享排他区，不能穿道路、门口、水面或已有建筑。

旧世界：本版可先替换树/花的视觉形态、改善外围地点；不在无迁移设计的情况下切开已建地基或重排旧村落。真正改变高度/水系的峡谷生成需要独立地形版本与旧世界保留策略，先做固定 seed 的新旧并排 demo 再采用。

## 远景不能糊成团

- 地形远景保留峡谷负空间、河道和岸线，不能用粗格跨过沟壑。
- 结构 LOD 保留船首/船尾/桅杆、屋顶/街巷、营帐/篝火等轮廓；不用一个包围盒替代整座结构。
- 花丛远景简化为数个低矮色块，树保留分层叶冠；靠近恢复实际方块和模型。切换用迟滞，避免镜头旋转或缩放时闪跳。
- 基于投屏尺寸和轮廓保护点选择细节，而不是只按全世界固定距离判定。先检查最远合法缩放下是否仍能识别地点。

## 本版正式采用范围

- `scenery.ts` 持有确定性规划；主世界默认生成，蓝图小预览关闭。保留既有地形高度、水系、任务/奖励位置，不新增地形版本或要求旧数据迁移。峡谷/新水系仍是可选后续扩展，不把研究内容库记为全部实现。
- 山谷/海岛各一处三户村落，附井、农田和衔接入口的小路。候选距任务核心至少再留 43 格，优先更远、默认镜头可辨认的地点；拒绝水面/大坡度/保护区，无合适位置则省略，空岛明确无村庄。
- 连续坐标噪声形成草甸、橡木/白桦林和较高处的针叶林斑块；真实单格树木合批，共享原创/导入包路线。花园以四种花、局部物种偏好和密度梯度组合，不沿建筑零散挂模型。
- 山谷的营地/残垣、海岛的营地/码头/近岸半露沉船、空岛的小型苔石按真实地表和占地排他落位。海面候选来自有效岸线采样，不能只用覆盖整片海面的水面 quad 中心判断；不保证每个 seed 同时出现所有地点。
- 每个结构按自身投屏宽度与迟滞选择完整/远景方块；省略室内等细节但保留屋顶阶梯、墙、船体与桅杆。背景扩展裁剪与适用阴影范围，不让背景改变任务聚落的构图适配。
- 新主世界图片/实际布局留存 `artifacts/v2.2.0/integration/targeted-06/`；固定三环境验证任务位置、地形与相机适配相同，背景没有业务身份。海岛默认远景已目视辨认船体与断帆；这是本机浏览器证据，Android/OEM 体验待新版包。

## 首个可审阅原型的历史范围（2026-09-30，已被正式方案取代）

- `scenery-prototype.ts` 持有确定性的只读地点规划与自写方块结构，复用现有资源包模型/图集和原创静态方块路由，不复制上游 NBT。山谷与海岛各三户；空岛因既有陆地空间较小，采用两户紧凑村落，均附井、农田、局部小路和混合花丛。
- 采用原有地形的真实顶面采样，检查水位、坡度、任务/奖励占地及道路；落地不足时省略地点，不扩大陆地、不移动旧建筑。当前固定种子的三个位置均有效，但不能推导所有种子都有可用位置。
- 树由单格树干/枝条和分层叶块构成，保留原有可用树位；这不是已完成连续群系噪声或新的森林分布规则。原有树位不足的空岛仍没有强制种一圈树。
- 结构按自身投屏宽度切换细节并带迟滞；远景保留屋顶阶梯、墙和地基，只省略门窗/室内等小细节，不压成包围盒。树目前保留真实方块，尚需正式密度/开销策略。
- 原型开关仅在开发/test-mode 生效，默认不启用；不用伪任务或伪奖励承载背景，不开放建筑记忆。标准运行路径仅受共享麦田原创形状、木楼梯/半砖木种配色与耕地土色修正影响。
- 近景是专用造型检查镜头，临时隐藏云和雾，不代表产品增加平移功能；远景仍用正式世界相机。背景阴影覆盖、真正的码头/营地/沉船/遗迹、峡谷和地形版本/旧世界策略仍待后续，不能把本原型记为 D01 全部完成。
- 本机证据与可审阅页面：`artifacts/v2.2.0/scenery/implementation-01.json`、`demo-final-original/`、`demo-final-pack/`、`review.html`；详见版本工作包，不是 Android 验收或公开素材交付。

## 用户确认的场景层级

- 在外围一个较远的位置生成背景村庄，不围绕任务聚落生成一整圈；任务建筑仍是画面主角。背景村庄不提供任务点击、进度、统计、奖励或建筑记忆。
- 造型采用用户确认的 MC 原版方向：由实际方块构成树和建筑，原版风格屋顶、门窗、井与小片农田形成一个地点；有资源包走现有纹理/模型路由，无包保留对应方块形状。不能用几块倾斜大盒子代替。
- 三环境保留原有地貌，叠加连续群系与可用地点；海岛采用岸边渔村意象，经典空岛不生成村庄或凭空增建环形大陆。
- 用户已审阅三环境固定 seed 的近/远景 demo 并授权正式实施；本版后续验证实际主世界、地点轮廓与任务身份。会改变旧地基高度的地貌步骤仍需独立的旧世界策略。
- 采用外观方向不等于新增第三方资产分发授权；本机参考与用户导入继续本地使用，公开源码只保留自写生成代码和可分发资产。
