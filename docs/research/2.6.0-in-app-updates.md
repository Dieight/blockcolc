# v2.6.0 App 内更新接入

2026-10-07。用户确认：标准版 App 内下载，私人版只提示公开更新，不用公开包覆盖好友同步模块。

## 选型

下载交给 [Android DownloadManager](https://developer.android.com/reference/android/app/DownloadManager)，避免在 WebView 内存中存放整包；退出 About 或进入后台不取消传输。进度通知只在下载过程中展示，验证后由 App 提供安装按钮。

下载元数据来自 [GitHub Release assets](https://docs.github.com/en/rest/releases/assets)，只接受本项目正式标准 APK 的准确文件名、地址、大小和 SHA-256 digest。下载后再检查实际摘要、包名、版本和当前安装的签名；私人通道在原生侧也拒绝公开包。

Android 8 及以上使用 [canRequestPackageInstalls](https://developer.android.com/reference/android/content/pm/PackageManager#canRequestPackageInstalls()) 检查此来源的安装授权。授权、下载与打开系统安装页面分别由对应操作触发，不静默安装。下载和验证失败不触碰应用事实或备份。

## 当前入口

- 标准版：默认关闭的“自动检查并下载”，手动检查后“确认下载更新”。关于页能看进度、取消和重试；安装另行确认。
- 私人版：沿用公开版本检查，只给提示和发布说明，不显示下载或安装按钮。
- Web：不冒充 Android 安装流程，保留公开发布说明入口。

实现职责见 [ARCHITECTURE](../../ARCHITECTURE.md)，行为见 [BLOCKCOLC](../../BLOCKCOLC.md)，检查结果记在 [开发记录](../versions/2.6.0-development.md)。实际 GitHub 下载及 OEM 系统安装的端到端体验不等同于浏览器桥接模拟和原生单元验证。
