# v2.6.0 普通／极简转场审看

日期：2026-10-07。状态：双向传送门已按用户最新编排接入正式界面；前两稿未采用，2D 色块本版弃置。
关联需求：[DEV-260-10、DEV-260-11](../versions/2.6.0-development.md)。

## 问题

普通与极简之间的过渡偏硬。前两稿都把世界放在全屏上，没有覆盖正式版普通模式上方的小世界、下方计时区和不同按钮位置。用户提出用完整传送门的进入／退出遮住布局交接；2D 色块本版弃置。

## 当前方案：完整传送门

审看入口 `apps/web/review-2.6.0.html` 的手机区域直接运行正式 `App`，不另画计时页。正常模式和极简模式保留各自布局、玻璃及原位置按钮；仅为方便反复审看，空闲时的“返回完整模式”持续可见。示例有八栋建筑，使用独立内存服务和存储，不读取本机任务、设置、材质包或定位。

用户进一步确定了不对称编排：普通入口是绿色像素空框，屏幕边缘从左下顺时针逐块筑门，约 1 秒完成，再以紫焰点亮内场；仅中心涡旋旋转，准备好后用 500ms 中心遮罩收拢露出极简页。返回时紫焰先腾跃，再摇曳至准备完成，随后扩满并出现门框，用 500ms 圆形开洞从内向外露出普通页。门不再从按钮放大或缩回按钮。完整覆盖后才执行展示切换，交接等待实际布局稳定与世界新帧，不添加固定加载等待。普通／极简换画幅是正常布局变化，不是拉伸世界，也不销毁 renderer 或重建建筑。重复点击在当前转场结束前忽略，减少动态时直接执行原切换。

门框和能量纹理为原创代码图形，不携带 MC 资源。当前实现位于 `apps/web/src/mode-portal.ts`；审看入口也使用这一份正式实现，不再拦截点击另播原型。

番茄按用户最新要求简化为 Y 型芽、完整茎、青果、成熟和落地消失；果实完全落地后轻弹一次再消失，茎长好后只循环果实。原四款房屋风车保留，真实加载不会为了动画等满一轮。

已有定点确认正式入口的浅深往返、完全遮挡下交接、同一 canvas 与 renderer、无世界重建及减少动态；番茄落地反弹和后台暂停也已检查。最新逐块筑门与圆形开洞另有实景定点，不沿用旧颜色或旧编排的截图。各阶段命令和报告见开发记录；浏览器结果不代表手机帧率。

## 前两稿依据（历史）

样例调用当前工作区的 `createVoxelRenderer`，使用十二栋内置建筑、`world-default` 种子、地形版本 4、2026-10-07 15:00 和同一镜头。审看页不读取或写入本机任务。浏览器入口是 `apps/web/review-2.6.0.html`，实现位于 `apps/web/src/review/`。

会话中展示的世界图片来自这个入口的实际渲染截图；转场由可点按的面板演示。实时入口保留旋转、缩放与海岛／海岸切换，便于进一步比较。第二稿只使用现有精致 3D，不再提供色块切换。

## 第二稿（未采用）

三款均保留世界原位。离场文字、共用时钟、玻璃面和导航分开编排；保留两套内容到各自动画结束，不在中途替换整个面板。

- **时钟迁移 · 1.4 秒**：施工信息先收束，时钟沿小弧线移向极简位置并逐步变大；玻璃调整边界，底部信息和按钮随后到位。反向时导航逐个回来。
- **玻璃折页 · 1.6 秒**：文字离场后，玻璃上下两半向中缝折起；时钟停留在上层，两片展开为目标面板，再引入文字和导航。
- **层片重组 · 1.55 秒**：玻璃分成四层，交错平移、轻微倾斜后重组；时钟独立衔接，文字最后分批出现。

三个方向共用真实世界与审看用动画实现。会话预览可往返；实际世界入口可在旋转、缩放后继续试切换。连续点击不卸载页面，最后一次目标排在当前动画后；减少动态时直接到目标状态。不写入应用设置，选定前不合入正式流程。

## 首稿记录

转场只动界面，不改变世界画幅和世界宿主：

- **玻璃上浮**：玻璃带小幅移入，标题和导航淡出；反向恢复。
- **纸页收拢**：用内容区域的收放表现切换，世界保持不动。
- **柔焦换景**：界面先柔焦淡出，再显示另一种布局；不模糊世界。

2D 两款共用真实几何、相机和拾取，替换纹理及动态表面光照：

- **折面色块**：保留固定的顶面、左右侧面明暗，建筑更容易辨认。
- **平面色块**：同色面合成更平的轮廓，画面更接近平面印刷。
- **现有 3D**：保留作为同镜头对照。

以上三种短转场和 2D 两款都未被采用。2D 试验开关已从核心渲染器删除，源码和纯测试移到 `artifacts/reviews/2.6.0/withdrawn-world-print/`；截图和首稿会话预览保留，不加入正式画质设置，也不声称获得了性能收益。
