# 方块钟 · 林间工坊

2026-10-13 UI 提案 01。对应[审计与设计说明](../2.7.0-ui-audit-20261013.md)。

直接用浏览器打开同目录 `index.html` 即可，文件协议已验证。也可以从仓库根目录运行：

```powershell
node docs/research/ui-demo-20261013/preview.mjs
```

终端输出本机预览地址（默认 `http://127.0.0.1:41990/`）。关闭终端或按 Ctrl+C 停止；端口冲突时可用 `BLOCKCOLC_DEMO_PORT` 指定其他端口。无需安装依赖、构建或连接外部服务。

建议依次看：计时页调整到三轮 → 开始 → 结束并汇报；任务页切换当前小任务；统计页点选、拖选，或聚焦日历后用方向键与 Shift 扩展；设置页切换主题、字体及两项减少偏好。顶部审看栏也提供快速切换，手机页尾可打开设计说明。

## 范围

- 所有任务和统计都是明确标识的合成示例；只使用页面内存，不访问正式 localStorage / IndexedDB / 原生桥接，不发送 API 请求。
- 倒计时是示例交互，不写真实专注记录，不自动接续所有轮次。汇报提交演示 2 秒完成反馈，示例统计保持不变。
- 新建任务只创建示例列表卡；偏好导出下载带独立格式标识的 JSON，不能作为正式应用备份导入。
- 世界图片是当前渲染器的静帧，不支持旋转或缩放。设计说明列出了其余未接入的正式功能。
- 此目录不被应用入口引用，不随当前 APK 打包。原型色值与设置分组尚不是已批准的正式产品要求。
