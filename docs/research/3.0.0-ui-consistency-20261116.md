## 范围与依据

以 /11 对应原生源码为基准，读取实际 Compose 公共组件和页面调用；不套用此前 Web 审计的颜色数量或字号数量。源码中的 `sp` 是系统文字缩放前的值，`dp` 是布局单位，两者不能与截图的物理像素混记。静态清单包含条件分支，不代表这些元素会在一屏同时出现。

可重跑的[源码清单](../../artifacts/experiments/v3.0.0/ui-audit-20261116/inventory.json)保存调用位置、参数、字号覆盖、尺寸与输入摘要；[生成脚本](../../artifacts/experiments/v3.0.0/ui-audit-20261116/inventory.py)只读取源码。下文的颜色是定义值，没有把它们当作实景对比度测量。

## 已按要求修改的两项

1. 好友入口原先复用任务清单图标，现为同一 12×12 网格中的双人方块轮廓，名称、44dp 触摸区域及可访问名称保留。只新增原生图标，不改 Web 或导航的任务图标。
2. “上一版”按最近交付 /11 的上一包 /10 处理。对照冻结的 /10 源码，撤回浅色背景的额外亮度下限和深色白天的额外亮度上限；散射、饱和度、色罩曲线及夜间高通透度处理与 /10 一致。保留同帧采样、视口修复和文字按主题／材质选择黑白的逻辑。没有改用户保存的通透度百分比。

这两项目前仅在工作树；已安装 /11 APK 不会自行变化。大范围版式和文案尚未替换。

## 任务、统计的字号

公共入口：`NativeTheme` 定义样式，`NativeText` 选择角色。主页面的常规文字已经集中为下列五档，但按钮和图表仍有旁路。

| 最终字号 | 任务页使用位置 | 统计页使用位置 |
| --- | --- | --- |
| 12sp | 新增／查看／切换等文字动作；进度与状态；完成计数、习惯说明、便签完成分组 | 日期上下文、统计说明、档案详情、解锁日期、图例、空状态 |
| 16sp | 目标名称与单位、小任务名称、便签正文；主／次按钮 | 分区标题、成就名称、档案标题；时长单位；异常重试按钮 |
| 18sp | 习惯周期的轮次数值、分区标题 | 完成轮次／目标、活跃日；展开成就后重复的内层标题 |
| 24sp | 页面标题、当前大任务名称 | 页面标题 |
| 32sp | 今日已完成轮数 | 总投入和纪念建筑投入中的数字，单位另为 16sp |
| 随容器缩小 | 无此直接覆盖 | 热力图标注为 `11 × 宽度 / 350 sp`；投入团簇名称和时长为 `12 × 宽度 / 400 sp` |

例如 360dp 页面，扣除两侧 20dp 和热力图卡片的两侧 17dp 后，标注约 9sp；团簇卡片两侧为 15dp，文字约 8.7sp。这里是按源码计算的示例，不是手机实测值。图表用固定比例缩放画布时顺带缩字，是比常规文字角色更明显的残留问题。

字体还分三条路径：纯像素全部用 Fusion Pixel；系统模式用系统字体；混合模式的正文和任务名用系统字体，数字和短操作标签用像素字体。12sp 的像素文字按钮与旁边 16sp 的系统任务名叠在一起，会加重大小不一的观感。

建议：保留现有 12／16／18／24／32 的基本层级，明确为页面标题 24、卡片／大任务分组标题 18、正文与交互按钮 16、主要数字 32、辅助信息 12sp；复合时长仍保留数字和单位的分工。图表文字固定为至少 12sp，放不下就增加排布空间、换行或缩短日期，不缩小字。纯像素依旧不靠不存在的粗体制造层级。

## 按钮、图标和颜色

| 组件／用法 | 文字 | 图标可见尺寸 | 当前前景／底色 | 问题 |
| --- | --- | --- | --- | --- |
| `FormalTextAction`：新增任务、查看建筑、新增小任务、切换、删除当前任务 | 12sp，混合模式为像素 | 22dp | 可用时强调绿，禁用时次要文字色；无填充 | 小字配较大的图标；连删除入口也呈强调绿 |
| `NativeIconAction`：好友、调整、编辑、选择小任务、排序、删除小任务 | 无可见文字，有可访问名称 | 默认 24dp | 强调绿；禁用时次要文字色 | 编辑／删除／选择几类不同动作相同颜色；与其他图标动作尺寸不同 |
| `NativeAction`：选择下一栋、确认删除、统计失败重试 | 16sp 短操作字体 | 19dp | 主操作绿底；次操作正文色配边框；危险确认红底 | 重试和普通文字入口的颜色、大小差异较大 |
| `NativeNoteAction`：便签新增、保存、取消、删除 | 无可见文字，有可访问名称 | 18dp；叉号 16dp | 跟随正文色；禁用降至 45% | 与任务卡片中的同类新增、编辑、删除按钮不同 |
| 折叠标题行 | 通常 16sp；描述 12sp；计数可为 12 或 16sp | 展开箭头默认 24dp；额外前导图标 20dp | 标题继承正文色；归档耗时又显式用绿 | 同一级成就／纪念建筑计数字号不一致 |
| 热力图档位 | 12sp | 8dp 数据色块 | 文字正文色，色块为数据分档 | 属于数据选择器，不应硬改成与新增按钮一样的样式 |

任务页图标清单：`plus` 新增、`friends` 好友、`edit/check` 调整与编辑、`cube` 建筑、`play` 选择／切换、`chevron` 排序、`minus/close` 删除、`note` 便签；状态另有 `flag/check`。统计页使用 `clock/flag/cube/trophy/check`，折叠箭头及异常重试按钮。状态图形不算操作按钮。

当前大多数操作色已经引用同一个色板，但不同组件选择了不同前景角色：

| 语义 | 浅色 | 深色 |
| --- | --- | --- |
| 强调绿 `primary` | `#276749` | `#6fce96` |
| 正文 `onSurface` | `#17211c` | `#e6efe9` |
| 次要文字 `onSurfaceVariant` | `#58635d` | `#afc0b3` |
| 表面 `surface` | `#ffffff` | `#17211c` |
| 分隔／弱边框 `outlineVariant` | `#d7ddd8` | `#2c3a31` |
| 危险 `error` | `#b4232c` | `#ff8a8a` |

图表另有有意不同的数据色：热力图四档绿，投入团簇五种绿。它们需要浅深主题各自适配，但不用与按钮合成一个颜色。

建议采用统一动作规格：16sp、20dp 图标、图文间隔 8dp、独立触摸区域至少 44×44dp。实心主按钮保持绿底；一般图标／文字动作使用正文色，选中、关键动作与进度用强调绿；危险确认用红，删除入口用较安静的文字／图标，保留确认和后果。便签的勾选框目前为 26×44dp，后续应扩展触摸区，同时保留编辑手势。

## 间距与层级

| 位置 | 当前定义 | 建议 |
| --- | --- | --- |
| 页面 | 左右 20、顶 22、底 32dp；区块间 24dp | 保留页面边线，统一上下基准 |
| 任务卡片 | 默认内容边距 12dp，便签为 18dp | 同级内容统一 16dp |
| 统计卡片 | 总览 16、投入 14、档案 20dp | 同级内容统一 16dp |
| 卡片边线 | 卡片还额外加入一圈 1dp 内边距 | 计算对齐时计入，避免只统一显式 padding |
| 小任务／便签 | 小任务最小 78dp、上下 10dp；便签最小 44dp；标题说明间 3 或 6dp | 行高按内容与触摸区决定；标题说明统一 4dp，不用给一行文本固定大高度 |
| 动作排列 | 图文间隔 6／8dp；行动区域有 8／12／16dp 等值 | 图文 8dp，同一组动作共用一个规格 |
| 统计块 | 指标间 18dp、档案项间 10dp、图标旁 5／8／10dp | 小关系 4／8dp，内容行 12dp，卡片 16dp，区块 24dp |
| 空状态 | 投入空状态上下各 36dp | 空状态保留一行可执行提示，避免大空白卡片 |
| 成就／档案 | 折叠标题下又出现标题和段落，档案内再缩进 16dp | 删除重复标题与解释，保留标题、数值和实际内容 |

不把图表坐标、物理滑杆轨迹或像素图形的几何数值强行改成上述间距。

## 设置页

设置的数值／开关／折叠行没有左图标，`NativeSettingLink` 却固定有 20dp 左图标与 12dp 间隔，故“账户”“新手教程”“关于”等会比普通选项右移 32dp。即便文案字号相同，左边线仍不一致。

建议普通设置行统一不放左图标，全部标题沿同一左边线；右侧用数值、开关或进入箭头表明功能。必要的功能按钮仍保留像素图标，页面导航与品牌图形保留。另一个可选方向是给所有一级设置配同规格图标，但会引入更多视觉元素。

按钮位置按它作用的对象安排：

| 现状 | 建议位置／表现 |
| --- | --- |
| 天气重新同步跟在两行状态右侧；与主选项的控制列不同 | 主行右侧统一刷新入口，下面只显示实际状态；同步时图标旋转，行高不跳 |
| 世界色彩的默认操作与下方多个滑杆混放 | “世界色彩”展开标题右侧；恢复只影响本组 |
| 生日日期的保存图标挤在折叠箭头旁 | 日期展开后与月／日输入放同一操作区，明确文字“保存”；不与展开箭头并排争夺触点 |
| 蓝图库／材质包内为多排大按钮；相同导入／刷新位置不一 | 组标题／工具行右侧统一导入、刷新；行项右侧只放该项操作 |
| 本地备份三级结构里按钮大小和标题层级交错 | 保留已确认的三个同级折叠项，统一各级标题和右侧操作列，不再加新的标题层 |
| 主题等分组选项前上边距为 12dp，聚落相关为 8dp | 由同一设置行组件决定标签到控件的距离 |

上述位置是提案，尚未全页替换。

## 计时调整的四种方案

共同约束：按当前 `NORMAL_WORLD_FRACTION=.45f`，普通世界保持导航上方可用高度的 45%，不扩大成满屏世界；仅修改草稿，确认才改变计划，确认不开始专注；按结束时间不选小任务；习惯任务点击直接选，普通项目下只列未完成小任务；手动取消保留原计划。示意只接合成数据，选择不写入应用。

| 方案 | 操作和布局 | 取舍 |
| --- | --- | --- |
| 分离选择（建议） | 调整弹页先显示当前任务摘要和轮次／截止；点击任务行在同一个弹页中切到选择视图，返回保留草稿 | 计划区短而清楚，完整任务树不会挤走时长与确认；换任务多一次进入／返回 |
| 就地快调 | 普通计时页进入编辑状态，在原工作台内调整轮次／截止；任务单独选择，确认后还原开始按钮 | 常用改动快，世界稳定；会改计时首页的局部结构，需要更多状态边界 |
| 分步安排 | 固定轮次分为选任务、排时长两步；按截止直接进入时间安排 | 一步一件事，字号和空间充足；普通改轮次也多一次导航 |
| 折叠工作台 | 同一调整弹页中用任务摘要折叠完整选择树，时长／确认始终在底部 | 接近现有交互、改动较小；展开大量任务时仍需要滚动，底部要固定 |

四个方案复用现有颜色、像素图标和字体模式。展示用于选择布局和操作路径，玻璃散射与物理手势仍以原生实现为准。

四种方案已分别在 320／736／1024px 视口检查选择任务、轮次／截止切换、键盘调整截止时间、确认后返回首页和控件边界，12 组通过；检查的是提案，不等于原生 App 的交互验收。[提案检查记录](../../artifacts/experiments/v3.0.0/ui-audit-20261116/qa-r3/plan-options-check.json)保留输入摘要。普通世界比例依据当前源码的 45% 处理，场景使用已有原生绘制截图的静态预览。

## 验证与下一步

本轮只验已改的图标导出／读取与玻璃参数，不跑全量、不构建或安装 APK、不继续 P4 采样。提案确认后先改公共动作、行与字号入口，再按两个页面和设置逐项采用；保留中英、浅深、三种字体、200% 文字、减少动态／透明度及长任务名的核对。危险操作和保存失败仍以原有业务结果为准。

## 决定

已采用：独立好友图标、按 /10 回退通透度、本轮文案原则，以及上述动作规格、间距、设置行对齐和文案去留。计时调整采用“分离选择”，固定轮次只保留加减号（1–24 轮），截止沿用原上下滑动；返回保留草稿，确认前不改正式计划。另核对横屏页面与弹层。长期要求已归入 [DESIGN](../../DESIGN.md)，实施和结果记入 [P3](../versions/3.0.0-p3.md)，本提案的浏览器检查仅是布局参考。
