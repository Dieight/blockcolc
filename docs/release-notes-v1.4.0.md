# Blockcolc v1.4.0 发布说明

## 世界常驻与沉浸专注

- 聚落世界现在跨页签常驻：回到计时页立即看到同一个机位的世界，没有加载页；离开计时页后渲染完全暂停。
- 专注页改为全屏沉浸：世界铺满整个屏幕，底部磨砂玻璃信息带，结束按钮默认隐藏、双击唤出（一次性提示说明手势，与按钮同样 5 秒节奏淡出），完整度计数只在变化时以徽章闪现。
- 开始一轮和完成一轮都会给工地一个脉冲反馈，每完成一轮当前建筑增长一格。

## 世界表现修复

- 修复了台阶侧面一整天的追查链条：
  - 雾界跟随真实地形范围——自然山谷的远山不再被雾吞成一片虚空色的墙，只保留薄雾层次；经典空岛雾值不变。
  - 台阶角部缝隙全部封闭——白天透白光、夜里透星星的角缝在新旧世界都不再出现。
  - LOD 环边界线按格子严格缝合——近/中/远三层环的边界线与邻环格子边完全重合，无论聚落扩建到多大都不会再出现边界白行（新增 30/60/100/150 栋建筑的回归矩阵）。
  - 台阶侧面变暗——近白的程序化纹理不再在低日照或灯照下溢出成纯白。
- 岸边水面不再有细亮缝；分型云恢复为清晰的方块堆叠，铺满可见天空，少量厚云贴在地平线。
- 导入的材质包现在会可见地重贴聚落地形与树木，切换包即时生效；蓝图改名标签在世界各处一致显示。

## 数据与兼容

- 本版本不改变存档结构、备份格式或资源包清单；老世界直接受益于渲染修复，无需任何迁移。
- 验证：全量单测 122 项、web E2E 77 项全绿；候选 APK 在 OnePlus PJX110 上安装并核对 SHA-256；上述白色侧面问题由用户实机逐坐标确认修复。
